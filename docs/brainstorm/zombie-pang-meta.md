## 핵심 원칙 — 결정론 Layer 1 + 가변 Layer 2 + 영구 메타 최소화

좀비팡의 메타 시스템은 세 개의 동심원으로 구성된다:

```
┌──────────────────────────────────────────┐
│  Layer 1: 결정론 (좀비 처치, 콤보, crit) │ ← 가챠/가변 0개
│  ┌─────────────────────────────────┐    │
│  │  Layer 2: 가변 (인테리어, 골드)  │ ← 챕터당 0.5회 가변
│  │  ┌──────────────────────────┐  │    │
│  │  │  영구 메타: starting deck │ ← 1장 선택권만
│  │  └──────────────────────────┘  │    │
│  └─────────────────────────────────┘    │
└──────────────────────────────────────────┘
```

이 분리가 사용자에게 의미있는 이유는, **빌드 자율성과 변별력은 카드(결정론)로 보장**하고 *작은 카타르시스*는 가변 보상으로 제공하지만, *영구 메타는 가볍게* 유지해서 *그만두기 쉬운 게임*이 되기 때문이다. Hades 패턴이 좀비팡의 메타 철학이다.

## 카드 15장 풀 — 4 Base × 3 Tier + Special 3

### Base 12장 (4 카테고리 × 3 티어)

| 카드 코드 | Tier 1 | Tier 2 | Tier 3 | 효과 | 인테리어 매핑 |
|---|---|---|---|---|---|
| **Damage** | 양손 회수 | 의자 휘두르기 | 정수기통 던지기 | +1 / +2 / +3 | 사옥 벽재 (합판→콘크리트→방탄유리) |
| **Crit%** | 정확한 한 방 | 빈틈을 노린 일격 | 카운터 펀치 | +5% / +10% / +15% | 회의실 조명 (형광등→스포트→무대) |
| **PowerUp Duration** | 점심시간 연장 | 야근 거부권 | 휴가 일수 추가 | +0.5s / +1s / +1.5s | 정수기 (3통→6통→자동급수) |
| **Coin Gain** | 잔돈 모으기 | 회식비 절약 | 성과급 협상 | +10% / +20% / +30% | 복합기 (흑백→컬러→A3 컬러) |

### Special 3장

| 카드 코드 | 카드명 | 효과 | 인테리어 컷씬 |
|---|---|---|---|
| Magnet Range | 자기장 ID카드 | 자석 PowerUp 범위 +20px | 휴게실 자판기 신설 (0.8초) |
| Combo Decay Resistance | 늘어지는 회의 | 콤보 유지 시간 +0.5s | 벽시계 → 모래시계 |
| Critical Multiplier | 사직서 한 방 | crit damage ×2 → ×2.5 | 사장실 책상이 비어 있음 |

**시너지 콤보는 v2로 연기**. MVP는 단일 스탯 부스트로 시작한다. 5장 × 3티어 = 243개 가능 빌드 (실질 변별력 ~40개)로 50층 끝까지 변별력이 유지된다. 시너지 콤보 카드의 텍스트 밀도가 portrait 가독성 한계를 초과한다 (mobile-ux-pragmatist).

모든 카드명은 *야근 속 작은 저항* 톤으로 통일되어 있다. "정수기통 던지기" "회의실 예약 취소" "복도 비상등 점등" — narrative와 mechanic이 분리되지 않는다. 카드 효과의 *숫자*가 곧 인테리어의 *변화*다. **메타 진행이 숫자 인플레가 아닌 공간의 회복으로 가시화**된다.

## 카드 unlock 페이스 — 3-stage

### Stage 1 (Day 0~3): 첫 게임 = 4 base Tier 1만

노출 카드 = Damage T1 + Crit% T1 + PowerUp Duration T1 + Coin Gain T1 (4장). 챕터 종료 시 3장 fan-out도 이 4장에서만 추첨된다. 학습 곡선을 단순화하기 위한 결정이다.

### Stage 2 (Day 3~14): 챕터 게이트

- 챕터 2 클리어 (누적 20층, 보스 #2 처치) → Tier 2 4장 unlock
- 챕터 4 클리어 (누적 40층, 보스 #4 처치) → Tier 3 4장 unlock

### Stage 3 (Day 7~70): 누적 coin 게이트로 Special 3장

- 누적 1000 coin → 자기장 ID카드 + 휴게실 자판기 컷씬 0.8초
- 누적 3000 coin → 늘어지는 회의 + 벽시계 → 모래시계 컷씬
- 누적 10000 coin → 사직서 한 방 + 사장실 책상이 비어 있는 컷씬

10000 coin = ~10주차는 길다. 출시 1주 데이터 검증 후 5000~10000 사이에서 조정 가능하다 (ADR-0007 Open).

**FOMO 방지 UX 규칙**: "다음 unlock까지 N coin" 텍스트는 long-press 시에만 노출된다. 진행 표시는 상단 6px 가로 바만 항상 노출. "처음 보는 카드"는 sparkle particle 6p 1초간으로만 표현되고 강제 모달은 없다 (ADR-0005).

## Daily Streak — 출근 도장, 상승 보너스만

좀비팡의 Daily Streak는 **상승 보너스만 있고 페널티는 0**이다 (ADR-0003 Resolved → Option B).

- "오늘 출근하면 +20% coin" — 상승 보너스만
- 끊겨도 **패널티 없음**
- 누적 방식 = 선형 +20%/일, 7일 상한
- 8일째도 +140% 유지 또는 자동 휴식 모달 ("연차 사용")
- streak UI = 벽시계 도장 7개. 끊겨도 도장은 *흐려질 뿐* 사라지지 않음

메인 메뉴 우측 상단 24×24px 배지로만 표시되고, 게임 진입 후 강조는 금지된다. *"오늘 출근 안 하면 streak 끊깁니다!"* 같은 카피는 없다. streak이 *접근 동기*로만 작동하고 *상실 회피*는 0이 된다 — WHO 행동중독 분류 거리를 최대 확보하기 위한 결정이다.

내러티브적으로 "벽시계 도장이 흐려진다"는 톤은 *야근 누적이 아닌 정시 퇴근 누적*을 시각화한다. 7일 출근 도장은 *야근 7일 강제*가 아니라 *7일 동안 정시 퇴근 7번 해냈다*는 기록이다.

## 가변 보상 Layer 2 — 인테리어 + 골드 폭증

가변 보상은 **두 가지 경로**로만 작동한다 (ADR-0002 Resolved → Option B):

### 1. 사옥 인테리어 재건 (가변)

방마다 회복 순서와 세부 사물이 다르다. 챕터 1 신입부서를 클리어하면 1~10층 인테리어가 *복구*되지만, 어느 방의 어느 사물이 먼저 회복되는지는 가변이다. 두 번째 풀런에서는 다른 방이 먼저 회복된다.

### 2. 골드 폭증 ×5배 (가변)

매 좀비 처치 시 **1~3% 확률**로 골드 폭증이 트리거된다. *"예상치 못한 야근 수당"* 톤의 미세 카타르시스다. 챕터당 평균 0.5회 발동 — PGSI(Problem Gambling Severity Index) 임계 미달 수준이다.

### 결정론 영역 (가변 아님)

- 챕터 종료 카드 3장 추첨 = **결정론 풀에서 균등 추첨**
- 시너지 콤보·power-up 드랍률 = 결정론
- Coin Gain Tier로 power-up drop rate 곱셈만 허용 (Tier 3에서 ×1.3 = 최대 6.5%)
- 덧셈 누적 슬롯머신화 금지 (ADR-0008 Resolved)

**플레이어 멘탈 모델용 표기**는 *"Tier 3에서 drop 빈도 증가"*라는 정성 표현으로 통일한다. *"최대 15%"* 같은 정량 표기는 사용하지 않는다 — dark-pattern-critic의 슬롯머신화 우려를 흡수한 결정이다.

## Power-up 3종 — 폭탄 / 빙결 / 자석

| Power-up | 효과 | 지속 | drop rate |
|---|---|---|---|
| 폭탄 | 화면 전체 좀비 즉시 처치 | 즉발 | 5% (보스 처치 시 30% 확정) |
| 빙결 | 모든 좀비 3초 정지 | 3초 | 5% |
| 자석 | 좀비 끌어당김 + 자동 처치 | 3초 | 5% |

3종은 균등 분포(각 33.3%)되고, **동시 활성 한도는 2개**다. 3종 동시는 portrait 컨트롤 책임 분산 임계를 초과한다.

자석 PowerUp drop 시 0.2초 자석 라인이 시각화된다. mobile-ux-pragmatist의 권고로 0.3초에서 0.2초로 단축되었다.

## 메타 보존 원칙 — 퇴근해도 모두 남는다

핵심 윤리 결정: **메타 기록은 퇴근해도 보존된다**. 챕터 중간에 *정시 퇴근*을 선택해도 그 챕터에서 획득한 카드, 골드, 인테리어 변경은 모두 저장된다. *진행 손실 페널티 = 강박 트리거*라는 원칙 때문이다.

이것이 좀비팡이 다른 캐주얼 게임과 갈라지는 지점이다. 대부분의 게임은 *세션 중단 = 진행 상실*로 사용자를 묶어둔다. 좀비팡은 *세션 중단 = 진행 보존*으로 **그만두는 비용을 0으로 만든다**. 그래서 사용자가 다시 켤 때, *streak이 끊길까봐*가 아니라 *원해서* 켜게 된다.
