## 2. Master Plan vs Code 불일치 상세

### 2.1 IClock Port 의미 정착 (본 세션에서 부분 정정)

| 위치 | master plan §6.3 명세 | 실제 코드 | 의미 |
|---|---|---|---|
| `IClock.now()` | epoch ms | monotonic ms (performance.now) | **불일치** — 코드가 monotonic으로 정착 |
| `IClock.monotonic()` | performance.now equiv | (본 세션에서 추가) now alias | **부분 정정** |
| `start-run.ts` | clock.now() 사용 | clock.now() (monotonic ms) | runId의 timestamp 의미 모호 |

**결론**: master plan §6.3을 코드 실제 의미에 맞게 갱신하거나, 코드의 `now()` 호출부를 `epoch`/`monotonic` 의도에 맞춰 분리해야 한다. 본 audit는 **코드 의미를 정착으로 인정**하고 master plan §6.3을 추후 PR에서 갱신할 것을 권장한다.
