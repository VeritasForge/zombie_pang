# ADR-0010: 층별 1단어 Narrative 텍스트 허용 여부

- **Status**: Open
- **Date**: 2026-05-17
- **Originated**: Phase A-2 Meta+Juice + Phase A-3 PWA+UX 토론 중 ux-craft가 "텍스트 0줄"을 강조했으나, narrative-architect가 층별 서사 깊이를 위해 "1단어 정도는 허용해도 좋다" 제안
- **Decision Drivers Conflict**: ux-craft(#3) ↔ narrative-architect(#5)
- **재논의 시점**: Phase B Master Plan (챕터 디자인 단계)

## Context

좀비팡의 챕터는 1F(현관 로비) ~ 12F(최상층) 또는 -B3(지하) ~ 12F의 층 구조다. Phase A-2에서 "텍스트 0줄 원칙"으로 합의됐으나, 다음과 같은 미세 표현은 허용 가능한지가 미해결:

- 층 표시: "7F", "B2" 같은 숫자 + 알파벳 (이건 layout 정보, 허용)
- 층 이름: "임원실", "사무실", "기계실" 같은 1단어 (이건 narrative, 미정)

narrative-architect는 "1단어는 서사 깊이를 크게 끌어올리지만 UI 노이즈가 거의 없다"고 주장. ux-craft는 "한 번 풀어주면 2단어, 3단어로 늘어나는 미끄러운 비탈"이라고 우려.

## Decision Drivers

1. 텍스트 0줄 원칙 보존
2. 서사 깊이 (B급 코믹 호러 톤 살리기)
3. UI 미니멀리즘
4. 다국어 대응 비용 (텍스트가 적을수록 i18n 부담 ↓)
5. 미끄러운 비탈(slippery slope) 위험

## Options Considered

| Option | 설명 | 찬성 | 반대 |
|---|---|---|---|
| **A. 완전 0줄 (숫자/알파벳만)** | "7F", "B2" 정도만 허용 | #3 | #5 |
| **B. 1단어 narrative 허용** | "7F 임원실", "B2 기계실" 식 | #5 | #3 |
| **C. 아이콘으로 대체** | 임원실 = 정장 아이콘, 기계실 = 톱니바퀴 아이콘 | (절충안) | (아이콘 학습 비용) |
| **D. 도입 챕터에만 1회 표시** | 첫 진입 시만 1단어, 재진입 시 숫자만 | (보조 옵션) | (예외 케이스 복잡) |

## Status: Open

권장 *C (아이콘으로 대체)*. Phase B 챕터 디자인 시 다음 검증:

- 12개 층(또는 -B3 ~ 12F의 15개 층)에 1:1 매칭되는 아이콘 디자인 가능한가?
- 아이콘만으로 사용자가 "어떤 공간인지" 이해 가능한가? (사용성 테스트)
- 아이콘 + 숫자(7F + 정장 아이콘)가 텍스트 1단어(7F 임원실)보다 i18n 비용이 낮은가?

검증 결과 아이콘이 부적합하다면, *B + 명시적 가드 룰*("1단어, 최대 4자, 추가 텍스트 금지")로 절충.

## Tentative Consequences

- **C 채택 시**: 텍스트 0줄 보존 + 서사 깊이 일부 회복. i18n 부담 거의 0. 아이콘 디자인 비용은 1회성.
- **A 채택 시**: 가장 엄격. 서사 깊이는 환경 디자인(배경 일러스트)에만 의존. narrative-architect 불만 잔존.
- **B 채택 시**: 서사 깊이 회복. 그러나 미끄러운 비탈 위험 + i18n 비용 발생 + Phase A-2 합의 일부 후퇴.
- **D 채택 시**: 예외 케이스가 늘어나 코드/디자인 복잡도 ↑.

## 후속 조치

- Phase B에서 12층 아이콘 세트 디자인 의뢰
- 사용성 테스트: 5명에게 아이콘만 보여주고 "어떤 공간이라 생각하느냐" 응답률 측정
