# ADR-CL-0002: 챕터 Fail → "조기 퇴근" 리프레임 톤

- **Status**: Resolved
- **Date**: 2026-05-17
- **Resolution Date**: 2026-05-17 (Phase A-2 Meta+Juice 토론 합의)
- **Originated**: Phase A-2 Meta+Juice 토론
- **Resolution**: 챕터 fail은 "조기 퇴근(early clock-out)"으로 리프레임. 메타(코인/카드 누적) 보존.

## Context

좀비팡의 챕터는 60초 타이머 + 다양한 fail 조건(미니보스 격파 실패, 시간 초과, 사용자 자발 종료)이 있다. 일반적 게임에서 "fail"은 부정적 피드백("패배", "실패")으로 처리되지만, 좀비팡의 "정시 퇴근" 컨셉은 이런 부정 톤과 정면 충돌한다.

- 부정 톤(예: "FAILED" 빨간 글자, 슬픈 BGM)은 사용자에게 좌절감을 줘 재플레이 압박 발생 → 다크 패턴
- 좀비팡의 톤(B급 코믹 호러 + 정시 퇴근)은 fail조차 "오늘은 일찍 퇴근했네!" 같은 따뜻한 리프레임이 자연스러움

## Decision Drivers

1. "정시 퇴근" 정체성과의 정합
2. 메타 보존 (사용자 노력은 항상 기록)
3. 부정 피드백 회피 (다크 패턴)
4. 페르소나 합의: ux-craft, narrative-architect, dark-pattern-critic 모두 찬성
5. game-feel-juicer: 톤 일관성 유지

## Options Considered

| Option | 설명 | 찬성 | 반대 |
|---|---|---|---|
| **A. 표준 fail 톤** | "FAILED" 표시 + 좌절 BGM + 메타 손실 또는 부분 보존 | (없음) | 다수 |
| **B. "조기 퇴근" 리프레임** | "오늘은 일찍 퇴근했어요!" + 메타 100% 보존 + 따뜻한 BGM | 다수 | (없음) |
| **C. 무톤(중립)** | 단순 통계만 표시 | (절충 가능하나 정체성 약함) | #5 |

## Decision

**Option B 채택: "조기 퇴근" 리프레임 톤, 메타 100% 보존.**

세부 규칙:

- 챕터 fail 시 화면 표시: "조기 퇴근 — 오늘 X마리, 콤보 Y, 코인 Z 획득"
- BGM: 일반 클리어 BGM의 ¾ 템포 버전 (슬프지 않지만 약간 차분함)
- 메타 갱신: 누적 코인/처치/콤보 모두 정상 반영
- 카드 unlock 진행도: 정상 누적
- Daily streak: clock-out 사유와 관계없이 "오늘 플레이함"으로 카운트
- 사용자 자발 종료(clock-out)와 시간 초과 사이 차별 없음

## Tentative Consequences

- **Pros**:
  - 정체성 일관성 (B급 코믹 호러 + 정시 퇴근)
  - 다크 패턴 회피 (좌절 + 재플레이 압박 없음)
  - 페르소나 만장일치 (분쟁 비용 0)
  - 메타 보존 → 사용자 노력 박탈감 0
- **Cons**:
  - 챕터 난이도 변별 약화 (fail/success 톤 차이가 미세) → 진행감 약화 가능
  - 사용자에 따라 "느슨하다"고 느낄 위험 (해소책: 카드 unlock 진행도로 진행감 보완)
- **고려사항**:
  - 미니보스 격파 실패 vs 시간 초과 vs 자발 clock-out 사이 미세한 시각 차이는 둘 것인지 (예: 자발 clock-out은 "정시 퇴근!", 시간 초과는 "조기 퇴근")
  - Phase C 구현 시 fail 메시지의 변종(variation) 3~5개 마련 → 반복감 회피

## 후속 조치

- Phase C-6(Juice 시스템) 구현 시 fail 시퀀스 단위 테스트 작성
- Phase C-9(폴리시) 단계에서 fail 메시지 카피라이팅 변종 확정
