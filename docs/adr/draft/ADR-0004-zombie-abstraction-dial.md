# ADR-0004: 좀비 추상화 다이얼 (50% 유지 여부)

- **Status**: Open
- **Date**: 2026-05-16
- **Originated**: Phase A-0 컨셉 토론 잔여 불일치
- **Decision Drivers Conflict**: narrative-thematist(#6) + game-feel-juicer(#2) ↔ dark-pattern-critic(#7)
- **재논의 시점**: Phase A-2 Juice 토론

## Context

좀비 4종을 *유기적 실루엣 + 표정 없는 마스크 (약 50% 추상화)*로 합의했지만, **이 다이얼의 정확한 값**이 미합의:

- 50% 유지 (사람 형상 + 마스크)?
- 더 추상화 (75% — 실루엣만 인간형, 얼굴 영역은 도형)?
- 완전 추상 (100% — 추상 잡념 덩어리)?
- 덜 추상화 (25% — 표정 있는 좀비)?

## Decision Drivers

1. 손맛 효율 (#2): fusiform face area 발화가 도파민과 결합 — 너무 추상화하면 손맛 23~40% 손실
2. 폭력 둔감화 (#7): 사람 형상 적의 반복 처치는 폭력 정상화
3. 서사 일관성 (#6): "기억을 잃은 동료" 메타포는 사람 형상이 필수
4. 글로벌 접근성: 명확한 인물 클래스는 톤을 빠르게 전달

## Options Considered

| Option | 추상화 다이얼 | 시각 표현 |
|---|---|---|
| **A. 25%** | 거의 사람 | 표정 있는 좀비 emoji 그대로 |
| **B. 50%** | 마스크 처리 (현 합의) | 인간 실루엣 + 표정 없는 마스크 |
| **C. 75%** | 실루엣만 인간형 | 윤곽 인간 + 도형 얼굴 |
| **D. 100%** | 추상 잡념 | 완전 추상 도형 |

## Status: Open

Phase A-2 Juice 토론에서 결정. 다음 추가 검토:
- A/B 테스트: 25% vs 50% vs 75% 처치 시 사용자 정서 응답
- "처치 시 죄책감" 자가 진단
- 5초 영상 prototype 비교

## Tentative Default

협상안 미합의 시 **Option B (50%)** 유지 — 손맛과 윤리의 절충점.
