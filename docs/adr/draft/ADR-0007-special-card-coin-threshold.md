# ADR-0007: Special 카드 Unlock Coin 임계 조정

- **Status**: Open
- **Date**: 2026-05-17
- **Originated**: Phase A-2 Meta+Juice 토론에서 Option B 채택 시 Special 카드(5장)의 임계값 결정. 5000/10000 coin은 잠정값으로 기록되었으나 실제 플레이 데이터 부재.
- **Decision Drivers Conflict**: meta-progression-strategist(#4) ↔ dark-pattern-critic(#7)
- **재논의 시점**: 출시 후 1주 데이터 확보 시점

## Context

좀비팡 Meta 카드 중 Special 카드 5장은 "장기 플레이의 보상"으로 5000코인 또는 10000코인 누적 시 unlock된다. 그러나 출시 전이라 다음 정보가 부재하다.

- 평균 세션당 코인 획득량 (60초 envelope 기준)
- 평균 일일 세션 횟수
- 평균 1주차 누적 코인량
- DAU 분포에서 임계 도달까지 걸리는 일수의 중앙값

5000이 너무 높으면 사용자가 "영영 안 풀린다" 좌절, 너무 낮으면 "왜 굳이 special이지" 의미 상실. 출시 전 휴리스틱 추정만으론 한계.

## Decision Drivers

1. 보상 회로 페이스(pacing): "도달 가능하지만 노력이 필요한" 영역
2. 좌절 회피 (3주 이상 무unlock은 retention 위협)
3. 의미 부여 (special의 "특별함" 보존)
4. 데이터 기반 의사결정 원칙
5. 사용자 신뢰 (출시 후 잦은 변경은 신뢰 손상)

## Options Considered

| Option | 설명 | 찬성 | 반대 |
|---|---|---|---|
| **A. 5000/10000 고정 (현재 잠정값 유지)** | 출시 후 6개월간 변경 금지 | #4 부분 | #7 (좌절 위험) |
| **B. 출시 1주 후 데이터 기반 재조정** | 1주차 누적 코인 P50을 기준으로 5000을 P40~P60 범위로 조정 | #7, #4 | (없음) |
| **C. 동적 임계 (사용자별 조정)** | 개인의 플레이 페이스에 맞춰 임계 조정 | (없음) | 다수 (공정성 훼손) |
| **D. 임계 제거, 시간 기반으로 전환** | "30일 누적 플레이"로 변경 | (보조 옵션) | #6 (변별력 감소) |

## Status: Open

권장 *B (출시 1주 데이터 후 재조정)*. 다음 KPI 기준 사전 설정:

- 1주차 누적 코인 P50이 5000 이상이면 그대로 유지
- 1주차 누적 코인 P50이 3000~5000이면 임계를 P50 값으로 하향
- 1주차 누적 코인 P50이 3000 미만이면 임계를 P50의 1.2배로 하향
- 10000 임계는 5000 임계 도달 후 1.5~2배 비율로 자동 조정

조정 결정은 한 번만 수행하며, 그 이후는 6개월간 고정한다.

## Tentative Consequences

- **B 채택 시**: 데이터 기반 의사결정 + 잦은 변경 회피. 첫 조정 후엔 신뢰 손상 없음.
- **A 채택 시**: 변경 비용 0이지만, 잠정값이 빗나가면 retention에 직접 타격.
- **C 채택 시**: 공정성 훼손. "다른 사람은 더 빨리 푸는데 나는?" 비교 박탈감 유발.
- **D 채택 시**: "오래 한 사람"과 "잘하는 사람"의 변별이 사라짐. Special의 정체성 약화.

## 후속 조치

- Phase B Master Plan에 "출시 7일 후 KPI 검토 회의" 일정 명시
- 텔레메트리 설계 시 일일 누적 코인 분포 추적 필수
