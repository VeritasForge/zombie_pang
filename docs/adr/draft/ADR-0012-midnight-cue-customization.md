# ADR-0012: 자정 Cue 시간대 사용자 커스터마이즈

- **Status**: Open
- **Date**: 2026-05-17
- **Originated**: Phase A-2 Meta+Juice 토론에서 ux-craft가 "자정 cue"(daily streak 갱신 시점)는 야간 근무자에게 부당할 수 있다고 지적
- **Decision Drivers Conflict**: ux-craft(#3) ↔ meta-progression-strategist(#4) ↔ accessibility-engineer(#2)
- **재논의 시점**: v2 (MVP는 고정 자정)

## Context

좀비팡의 Daily Streak(연속 출석)은 매일 자정(local time)을 기준으로 갱신된다. 그러나:

- 야간 근무자(간호사, 경비, 24시간 서비스 직원)는 자정에 일하므로 플레이 불가
- 시차 적응 중인 여행자는 자기 사이클과 어긋남
- "정시 퇴근" 컨셉의 게임이 정작 사용자의 라이프스타일을 강제하는 모순

해결책으로 사용자가 "내 자정"을 0~23시 사이에서 슬라이더로 설정 가능하게 하는 방안이 제기됐다.

## Decision Drivers

1. 접근성 (다양한 라이프스타일 수용)
2. Streak 시스템 무결성 (악용 방지)
3. MVP 범위 (구현 비용)
4. "정시 퇴근" 정체성 (사용자 자율 존중)
5. UI 단순함

## Options Considered

| Option | 설명 | 찬성 | 반대 |
|---|---|---|---|
| **A. MVP는 고정 자정, v2에서 슬라이더** | MVP는 자정 고정으로 출시, v2에서 0~23시 슬라이더 도입 | 다수 | (없음) |
| **B. 첫 출시부터 슬라이더** | MVP부터 사용자가 cue 시간을 자유 설정 | #2, #3 | #4 (구현 비용), #PM (MVP 범위 초과) |
| **C. 영구 고정 자정** | 변경 옵션 없음 | (없음) | #2, #3 |
| **D. 3개 프리셋(자정 / 오전 6시 / 오전 9시)** | 슬라이더 대신 3개 선택지 | (절충안) | (라이프스타일 다양성 부족) |

## Status: Open

권장 *A (MVP 고정 → v2 슬라이더)*. MVP 출시 시 사용자에게 "v2에서 커스터마이즈 예정" 명시.

v2 도입 시 다음 어뷰즈 방지책 포함:

- cue 시간 변경은 7일에 1회로 제한 (streak 강탈 방지)
- 변경 시 현재 streak 보존, 단 "변경 직후 24시간은 streak 카운트 안 됨" 등 정책
- "자정에서 23시로 바꾼 후 23:50에 플레이 → 곧바로 다음날 23:50까지 윈도우" 같은 악용 시나리오 차단

## Tentative Consequences

- **A 채택 시**: MVP는 단순 + v2에서 접근성 회복. 야간 근무자에게는 출시 후 일정 기간 불편하지만 명시적 로드맵 공유로 신뢰 유지.
- **B 채택 시**: 접근성 최대지만 MVP 범위 초과. 출시 일정 지연 위험.
- **C 채택 시**: accessibility-engineer 명시적 반대. 다양한 라이프스타일 배제.
- **D 채택 시**: 3개 프리셋으론 다양성 한계. 슬라이더보다 구현 비용은 낮지만 미봉책.

## 후속 조치

- MVP 출시 노트에 "v2 자정 cue 커스터마이즈 예정" 명시
- v2 슬라이더 디자인 시 어뷰즈 방지책 단위 테스트 작성
