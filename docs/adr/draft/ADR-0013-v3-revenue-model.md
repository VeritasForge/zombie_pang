# ADR-0013: v3 수익 모델

- **Status**: Open
- **Date**: 2026-05-17
- **Originated**: Phase A-0 컨셉 토론에서 ADR-0001(광고 통합)이 Open으로 박제되며, BM 자체의 장기 방향성이 미정으로 남음.
- **Decision Drivers Conflict**: meta-progression-strategist(#4) ↔ dark-pattern-critic(#7) ↔ business(#PM)
- **재논의 시점**: v3 (MVP 출시 후 3~6개월 데이터 기반)

## Context

좀비팡 MVP는 광고 0개 + 영구 무료(완전 free)로 출시 결정. 그러나 출시 후 운영 비용(서버, 도메인, 업데이트) 회수와 추가 콘텐츠 개발을 위한 수익 모델이 v3에서 필요할 수 있다. 가능한 방향:

- **카드 코스메틱**: 게임 플레이 영향 없이 카드 일러스트/이펙트만 변경 (skin)
- **챕터 팩 일회성**: 새 챕터 5~10개를 일회성 구매로 판매 (확장팩 모델)
- **광고 X, 영구 무료**: 기부/오픈 컬렉터블 등 비전통적 수익

## Decision Drivers

1. 윤리 가드 ("정시 퇴근" 컨셉과 BM의 정합)
2. 사용자 신뢰 (MVP "광고 0개" 약속 보존)
3. 운영 지속 가능성 (서버/개발 비용)
4. 콘텐츠 확장 동기
5. 다크 패턴 회피

## Options Considered

| Option | 설명 | 찬성 | 반대 |
|---|---|---|---|
| **A. 카드 코스메틱** | 게임 영향 없는 skin/이펙트 변경만 판매 (가격 $0.99~$2.99/장) | #7 (다크 패턴 최소), #4 | (수익 규모 작음) |
| **B. 챕터 팩 일회성** | "지하 -B5~-B10 챕터 팩" 일회성 구매 (가격 $4.99~$9.99) | #PM (예측 가능 매출), #5 (서사 확장) | (콘텐츠 격차 → 가진 자/못 가진 자 분리) |
| **C. 광고 X 영구 무료** | 기부/Patreon/한정판 굿즈로만 수익 | #7 | #PM (지속 가능성 ↓) |
| **D. A + B 하이브리드** | 코스메틱 + 챕터 팩 | (절충안) | (UI 복잡도) |

## Status: Open

MVP는 *C (영구 무료)*. v3 시점에 데이터 기반으로 A 또는 D를 재검토.

v3 의사결정 트리거:

- MVP 3개월 후 DAU/WAU 측정
- 콘텐츠 추가 요청(피드백)이 일정 임계 이상 누적 시 챕터 팩 검토
- 서버 비용 vs 광고 X 유지 가능성 분기점 측정

v3 도입 시 가드 룰:

- 게임 플레이 영향 0% (코스메틱만)
- 챕터 팩 도입 시 본편 무료 보존 (분리 가능한 확장)
- 어떤 BM도 "정시 퇴근" 컨셉과 정합 (예: "잔업 보너스" 같은 야근 유발 BM 금지)

## Tentative Consequences

- **MVP C 채택**: 광고 0개 약속 유지. 사용자 신뢰 최대.
- **v3 A 채택 시**: 게임 플레이 무영향 + 자발적 후원. dark-pattern-critic 만족. 수익 작지만 윤리적.
- **v3 B 채택 시**: 예측 가능 매출 + 콘텐츠 확장 동력. 단, 본편/확장 분리 시 사용자 차별 인식 회피 노력 필요.
- **v3 D 채택 시**: 최대 수익. UI 복잡도 ↑ 및 다크 패턴 회피 가드 정밀 설계 필요.
- **v3 C 유지 시**: 운영 지속 가능성 의문. 개인 프로젝트로 축소될 위험.

## 후속 조치

- MVP 출시 노트에 "영구 무료, 광고 0개" 명시
- 텔레메트리 설계 시 v3 의사결정에 필요한 KPI(DAU/WAU/retention/콘텐츠 요청)를 사전 정의
