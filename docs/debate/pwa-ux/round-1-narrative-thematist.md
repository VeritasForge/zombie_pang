# Round 1 — Narrative Thematist

## 입장: "UX의 모든 마이크로카피는 *B급 코믹 호러*를 노래해야 한다"

좀비팡은 단순한 캐주얼 puzzle이 아니다. **"야근 끝에 좀비 사옥 50층을 클리어하고 정시 퇴근"** 이라는 *알레고리*다. PWA + UX 결정에서 사소한 문구 하나, 사소한 사운드 하나가 이 알레고리를 살리거나 죽인다. 텍스트 0줄 onboarding에 동의하지만, *0줄에도 톤은 있다*.

## 핵심 주장

### 1. Splash = "퇴근 카드 찍는 순간"
- 로고 "OFF-CLOCK PANG" — 이 이름 자체가 narrative다. "퇴근 후" + "팡(타격감)".
- splash 배경은 ***형광등 깜빡임***. 사무실 야간 분위기 즉시 전달. (저전력 모드에선 깜빡임 1회로 제한 — reduce motion 대응)
- "Press Start" 대신 **"PUNCH IN"** (출근 도장). 끝 화면 "PUNCH OUT" 과 대응.

### 2. 첫 30초 = "엘리베이터 타고 1층씩 올라가는" 경험
- 층(floor) 카운터 = "1F → 2F → 3F ..." 좌측 상단 작은 LED 디스플레이 미감. 사무실 엘리베이터 패널 emulation.
- 좀비는 *동료의 좀비화* 라는 다크 코미디. **basic 좀비는 와이셔츠 + 넥타이, fast는 후드티 (개발자), tank는 정장 + 서류가방 (부장), boss는 CEO + 황금 넥타이**.
- 시각으로 "회사"임을 즉시 인지 → 텍스트 없이 세계관 전달.

### 3. powerup 자석 = "**커피 자판기**" 메타포
- 자석 아이콘 대신 ***커피잔 + 자력선*** 아이콘 추천. "카페인 끌어당김" 의미.
- powerup 발동 사운드는 ***에스프레소 머신 추출음*** + 매직 ping.
- 이렇게 하면 powerup마저 narrative 안으로 들어온다.

### 4. 도주 좀비 = "**다음 층으로 도망간 야근거리**"
- 도주 = 위로 빠져나가는 좀비 = "다음 층에서 다시 마주칠 일거리" 라는 다크 코미디.
- 누적 5 도달 = "야근 폭발" → 게임 오버 화면에 시계 23:59 표시 + "한 잔 더?" (재시도 버튼).

### 5. 챕터 클리어 = "정시 퇴근의 카타르시스"
- "PUNCH OUT!" + 시계 17:30 + 회사 건물에서 걸어 나오는 실루엣 1초 cutscene.
- meta-strategist의 카드 선택 화면은 **"퇴근길 자판기"** 미감 — 3장 fan-out이 자판기 옵션처럼.

### 6. 자정 cue — **이게 narrative의 정점**
- dark-pattern-critic이 제안한 "이제 자도 괜찮아요"는 narrative와 완벽히 일치한다. 좀비팡은 *야근 비판* 게임이다. 자정에 게임 켠 사용자에게 "**오늘 야근은 충분해요. 좀비도 잠들었어요.**" 같은 문구는 ***세계관 안에서*** 자연스럽다.
- 화면 디밍은 50% 동의. 사무실 형광등이 절전 모드로 들어간 미감.
- 이건 다크 패턴이 아니라 ***게임 세계관 자체의 일관성***이다.

### 7. install prompt 카피
- "**홈 화면에 두고 출근길에 켜세요**" — 기능적이면서 narrative와 연결.
- iOS 가이드 모달: "**[공유] → [홈 화면에 추가]** — 다음 야근부터는 빠르게 켤 수 있어요." 한 줄로 끝.

## 양보 지점

- 텍스트 0줄 onboarding에 동의. 첫 30초 동안 텍스트가 나올 자리는 **숫자(콤보 ×1.5, FLED 1/5, 1F~10F)** 뿐. 단어는 없다.
- 카드 선택 화면 텍스트는 필수 (meta-strategist 입장 지지). 단 카드 이름은 *짧고 다크 코미디적*: "야근 거부권", "엘리베이터 워프", "커피 폭주" 등.

## 우려

- "텍스트 0줄" 강박이 narrative 잠재력을 죽일 수 있음. **층 카운터의 미세한 텍스트 변화** (예: 7F = "임원실 층" 작은 텍스트)는 허용했으면 함. 단 영어 1단어, 폰트 작게, optional.
- juicer의 "둠 + 팡" 사운드는 좋지만 *사무실 미감*과는 약간 어긋남. 가능하면 ***스테이플러 찰칵*** + ***종이 찢어지는 소리***도 검토. 정 안 되면 기본안 OK.
- compulsion-architect의 "Variable Reward" 강조가 narrative와 부딪힐 위험. 카드는 *전리품*이 아니라 *오늘의 회고* 같은 톤으로. "획득" 대신 "오늘은 이걸 배웠어요" 같은.

## Round 1 결론

좀비팡의 모든 UX 결정은 ***"야근 끝내고 퇴근"*** 알레고리 안에서 일관성을 가져야 한다. PUNCH IN/OUT, 형광등, 커피, 자정 cue, 17:30 시계 — 이 모든 소품이 *세계관*을 짓는다. 텍스트 0줄에도 톤은 살아있어야 하고, 그 톤은 *다크 코미디 + 야근 풍자* 다.
