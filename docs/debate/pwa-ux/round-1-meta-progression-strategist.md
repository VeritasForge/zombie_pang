# Round 1 — Meta-Progression Strategist

## 입장: "PWA install은 meta progression의 0번째 단계다"

내가 신경 쓰는 건 두 가지다. (1) **install prompt 타이밍이 meta loop의 진입로**다. (2) **첫 30초가 카드 시스템의 hook을 어떻게 심느냐**다. PWA는 그저 컨테이너가 아니라 *progression이 저장되는 그릇*이다.

## 핵심 주장

### 1. Install prompt = "이제부터 진짜가 시작된다" 의식
- 챕터 1 클리어 직후 노출에 강하게 동의. 이유:
  - 첫 카드 3장 선택을 막 마쳤다 = 사용자에게 *자산*이 생겼다
  - "이 자산을 다음 세션에 이어가려면 홈에 있어야 한다" 라는 자연스러운 동기
  - install 거부 = localStorage에는 카드 남지만 ***notify가 안 닿는다*** 는 점은 명시 X (FOMO 회피, dark-pattern-critic에 동의)
- **노출 카피**: "홈에 두면 야근 끝낼 때 빠르게 켜요" 같은 *기능적* 문구. "지금 설치!" 같은 압박 X.

### 2. 첫 30초에서 meta hook 심는 법
- 60초 클리어 후 카드 3장 선택 화면이 진짜 hook이다. 첫 30초는 그저 "곧 카드가 온다"를 *암시* 만 해도 충분.
- 4층 powerup 자석은 ***세션 내 일시 효과*** 다. 챕터 클리어 보상 카드와 헷갈리면 안 됨.
- → powerup 자석 아이콘과 meta 카드 아이콘은 **시각적으로 명확히 구분**되어야 한다. powerup은 둥근 매직 아이콘, 카드는 사각 frame + 골드 테두리.

### 3. 챕터 1 클리어 → 카드 3장 → install prompt 순서
- 60초 envelope 종료 → CEO 처치 화면 정지 1초 → "PUNCH OUT!" 큰 텍스트 + 시계 17:30 표시 → 카드 3장 fan-out → 1장 선택 → 짧은 retrospective(사용 메커닉 요약 1줄) → **install prompt**.
- install 후/거부 후 → 다음 챕터 진입 또는 메인 메뉴.
- 이 시퀀스는 단순하지만 핵심: ***보상 → 선택 → 투자*** 라는 meta loop의 3박자가 첫 세션에 다 일어난다.

### 4. 오프라인 카드 보존
- localStorage 또는 IndexedDB에 카드 deck 저장. PWA 오프라인 = 전체 deck 사용 가능 = "지하철 야근족" 페르소나에 부합.
- 동기화는 v2에서 (계정 시스템 도입 시). v1은 device-local.

## 양보 지점

- **권한 요청 X**에 동의. notification 없이도 meta loop는 작동한다. retention은 *카드 컬렉션 완성 욕구* 로 만들고, 푸시 알림에 기대지 않는다.
- **자정 cue**에 동의. 오히려 "그만하라"는 cue가 다음 날 ***다시 켤 동기*** 가 된다 (Loss aversion + 자제 후 보상 심리).
- **텍스트 0줄** 원칙에 동의하되, 카드 선택 화면에서는 카드 효과 텍스트 필수 — 이건 onboarding 30초 이후 영역이므로 별개.

## 우려

- **install 거부 시 7일 cooldown**: 너무 길지 않나? 챕터 3 클리어가 다음 강력한 hook 시점인데, 평균 사용자가 챕터 3까지 도달하는 데 평균 4~5일 걸린다. 7일이면 정확히 다음 강한 시점 직후라 재노출이 적절. → **OK**, 7일 유지.
- **카드 선택 화면 시간**: 60초 envelope에 포함되나 별도인가? → 별도 권장. envelope은 *플레이* 단위, 카드 선택은 *메타* 단위.
- **첫 챕터 카드 선택 = 강제** vs **선택 가능?**: 강제 권장. 첫 세션에서 카드 선택을 안 하면 meta loop hook을 못 심는다. 단 "그만하기" 버튼은 카드 선택 후 노출.

## Round 1 결론

PWA는 *그릇*이 아니라 ***progression이 잠드는 베개*** 다. 챕터 1 클리어 → 카드 3장 → install prompt 순서가 meta loop의 1차 점화. 첫 30초는 powerup과 카드의 시각 구분만 명확하면 충분하다. 그 다음 30초 + 카드 선택이 진짜 meta hook 구간이다.
