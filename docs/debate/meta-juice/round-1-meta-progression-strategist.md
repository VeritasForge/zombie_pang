# Round 1 — Meta Progression Strategist

> 페르소나: 메타 진행 전략가 (영구 자산 / unlock 곡선 설계자)
> 단계: Phase A-2 Meta + Juice 토론 / Round 1
> 입장 강도: **매우 강 (Meta tree 주관자)**

---

## 핵심 주장

**Meta 카드 15장은 *수치 부스트 ↔ 세계관 인테리어* 이중 매핑이라는 골격 위에서, *unlock 페이스가 새로운 안건을 매주 만들어내는 구조*여야 한다.**
완전 unlock된 deck은 retention engine을 잃는다 — 그래서 *base 4장 즉시 / Tier 2·3 챕터 5 게이트 / Special 3장 누적 coin 게이트*
**3-stage unlock**을 제안한다. 동시에 *영구 메타는 가볍게* — Hades 패턴.

## 시드 질문별 입장

### Q1. Meta Tree 구조 — 15장 정확한 분류

#### 4 base × 3 tier = 12장

| 카드 | Tier 1 | Tier 2 | Tier 3 | 인테리어 매핑 |
|---|---|---|---|---|
| **Damage** | +1 | +2 | +3 | 사옥 벽재 강도 (얇은 벽→콘크리트→방탄 유리) |
| **Crit%** | +5% | +10% | +15% | 회의실 조명 (형광등→스포트→무대조명) |
| **PowerUp Duration** | +0.5s | +1s | +1.5s | 정수기 (3통→6통→자동급수) |
| **Coin Gain** | +10% | +20% | +30% | 복합기 (흑백→컬러→A3 컬러) |

#### Special 3장

| 카드 | 효과 | 인테리어 |
|---|---|---|
| **Magnet Range** | +20px (자석 PowerUp 범위) | 휴게실 자판기 추가 |
| **Combo Decay Resistance** | 콤보 유지 시간 +0.5s | 시계 멈춤 (벽시계 → 모래시계) |
| **Critical Multiplier** | crit damage ×2 → ×2.5 | 사장실 책상 (CEO 책상이 *비어 있음*) |

### Q1 시너지 v2 시점

- **챕터 5 클리어율 88%±5% 데이터 측정 후** v2.
- v1 출시 직후 시너지 도입은 *지각된 다양성*만으로 충분한 단계에서 *결정 비용*만 추가.

### Q7. 카드 unlock 페이스 — 3-stage

#### Stage 1: 첫 게임 (Day 0~3)
- 4 base 카드 Tier 1만 노출. 12장 중 4장 = 33%만 보임.
- 의도: *학습 곡선의 단순화*. "지금은 4가지 선택지" — 인지 부담 최소.

#### Stage 2: 챕터 5 클리어마다 Tier 2/3 unlock (Day 4~14)
- 5층 클리어 (= 챕터 1 클리어, 누적 5층) → Tier 1 *유지 + Tier 2 4장 unlock*
- 챕터 2 클리어 (누적 10층, 보스 #1 처치) → Tier 2 풀에 진입
- 챕터 3 클리어 (누적 15층) → Tier 3 4장 unlock
- 챕터 4·5 = 메타 deck 완성 신호

> **주의**: "챕터 5 클리어마다 Tier unlock"은 *각 챕터의 5번째 마다*가 아니라 *각 5단위 챕터 게이트 통과 시*로 해석.
> v1 단순화 안: **챕터 2 클리어 = Tier 2 unlock, 챕터 4 클리어 = Tier 3 unlock**.

#### Stage 3: 누적 coin 게이트 (Day 7~70)
- 1000 coin → Magnet Range unlock (휴게실 자판기 등장)
- 3000 coin → Combo Decay Resistance unlock (시계 멈춤 연출)
- 10000 coin → Critical Multiplier unlock (사장실 책상 비어 있는 컷씬 1회)

### Q3. 가변 Layer 2 범위

- **Option B 찬성**. 카드 가챠가 가변이 되면 *플레이어가 빌드를 계획할 수 없다* → 메타 deck의 의미 소실.
- 카드 = 결정론 풀 / 인테리어 + 골드 폭증 = 가변. 분리가 명확해야 메타 진행감이 *예측 가능한 즐거움*이 된다.

### Q2. Daily Streak

- **Option B 찬성**. streak 보너스 +20% × 7일은 *Special 3장 unlock 시간 단축* 동기로 연결.
- 단 **선형 +20%/일 누적, 7일 상한** (difficulty-balancer 제안 동의). 8일째도 같은 +140% 유지 또는 자동 휴식 모달.

### Q4. 좀비 추상화 다이얼

- **Option B 유지**. 좀비 4종의 *직급 인식*은 인테리어 매핑(부서별 배경)과 짝지어진 정보 — 50% 마스크가 직급 가독성 한계.

### Q5. Juice 카탈로그

- *meta unlock 순간*에 별도 juice 필요: "처음 보는 카드"가 fan-out 될 때 stagger 0.3초 + chime layer 5 변형.
- Special 3장 unlock = 별도 컷씬 0.8초 (사옥 외관에 새 영역이 칠해짐).

### Q6. Power-up drop rate

- 5% + 보스 30% 확정 *찬성*. Coin Gain Tier 3 누적 시 15%까지 곡선은 *메타가 게임 안 즐거움으로 환원되는 좋은 예*.

## 비대칭 양보

- Special 3장의 효과(+20px / +0.5s / ×0.5 multiplier)는 *수치 조정 가능*. unlock 임계값(1000/3000/10000)도 조정 가능.
- 단 **3-stage unlock 구조 자체**는 양보 불가.
