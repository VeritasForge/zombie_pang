## 핵심 주장

**Meta 카드 15장은 *수치 + 인테리어* 이중 매핑에서 *야근의 작은 저항*이라는 톤을 일관되게 유지해야 한다.** Juice 카탈로그의
SFX·시각 효과도 *사무 공간의 사물*에서만 추출. 외부 사운드 0 = *사무실의 자연음만으로* 합성된 손맛. 카드명은 *수치적 효용*이
아닌 *행위로서의 친절*로 명명되어야 한다.

## 시드 질문별 입장

### Q1. Meta Tree 15장 — 카드명 + 인테리어

#### 4 base × 3 tier

| 카드 코드 | Tier 1 명 | Tier 2 명 | Tier 3 명 | 인테리어 |
|---|---|---|---|---|
| **Damage** | 양손 회수 | 의자 휘두르기 | 정수기통 던지기 | 사옥 벽재 (얇은 합판 → 콘크리트 → 방탄유리) |
| **Crit%** | 정확한 한 방 | 빈틈을 노린 일격 | 카운터 펀치 | 회의실 조명 (형광등 → 스포트 → 무대조명) |
| **PowerUp Duration** | 점심시간 연장 | 야근 거부권 | 휴가 일수 추가 | 정수기 (3통 → 6통 → 자동급수기) |
| **Coin Gain** | 잔돈 모으기 | 회식비 절약 | 성과급 협상 | 복합기 (흑백 → 컬러 → A3 컬러) |

#### Special 3장

| 카드 | 명 | 효과 | 인테리어 |
|---|---|---|---|
| Magnet Range | **자기장 ID카드** | +20px (자석 PowerUp 범위) | 휴게실 자판기 신설 |
| Combo Decay Resistance | **늘어지는 회의** | 콤보 유지 +0.5s | 벽시계가 모래시계로 |
| Critical Multiplier | **사직서 한 방** | crit ×2 → ×2.5 | 사장실 책상이 *비어 있음* |

> *사직서 한 방*은 50층 엔딩의 메타포 회수. unlock 임계(10000 coin)까지 가는 *최후의 저항* 톤.

### Q5. Juice 카탈로그 — 톤 일관성

#### Particle 변형 규칙 (서사적 의미)

- **사원증**: 신입 좀비 처치 시 — *입사 첫날의 흔적*
- **종이 (A4)**: 과장 좀비 — *결재되지 못한 보고서*
- **커피잔**: 팀장 좀비 — *식어버린 야근의 동반자*
- **USB**: CEO 보스 — *데이터 유출, KPI의 잔해*
- **명함**: 과장+팀장 혼합 시 — *교환되지 못한 연결*
- **포스트잇**: 신입+잔불 — *전달되지 못한 메모*
- **클립 / 스테이플러 심**: combo 5+ 강조 — *고정의 도구가 풀어지는 순간*

#### SFX 톤 가이드

- Layer 1 (impact 80Hz square): 의자 다리가 책상에 부딪힌 둔탁한 소리 톤
- Layer 2 (zombie groan): 회의실 마이크 피드백 / 복사기 동작음 톤
- Layer 3 (crit punch): 결재 도장 *쾅* — 4-layer 합성의 *주제음*
- Layer 4 (combo "팡!"): 풍선껌 터지는 톤 / 회사 단톡방 알림음의 비유
- Layer 5 (powerup chime): 자판기 동전 떨어지는 톤
- Layer 6 (wave clear fanfare): 엘리베이터 도착 *띵* + 화답 코드
- Layer 7 (hit damage): 형광등 깜빡이는 *틱* 음

#### "팡!" 의성어

- 사무실 톤 유지. 폰트는 굵은 sans-serif (Pretendard Black 권장). *카타카나·영문 금지*.
- 색: #FFCE00 (포스트잇 노란색) + stroke #1A1A1A (회의실 칠판).

### Q4. 좀비 추상화 다이얼

- **Option B 유지**. 75%로 가면 직급(신입/과장/팀장/CEO) 메타포 소실. 50% 마스크 = *얼굴은 비어 있지만 직급은 남았다*는 핵심 서사.
- 마스크 표면 텍스처에 *직급별 작은 사인*: 신입(흰색), 과장(회색), 팀장(어두운 회색), CEO(검정).

### Q3. 가변 Layer 2 범위

- **Option B 찬성**. *인테리어의 회복*만 가변이 되어야 한다. 카드 = *결정의 단위*, 인테리어 = *세계의 단위*.
- 골드 폭증은 *예상치 못한 야근 수당* 톤. 1~3% × 5배 트리거 시 "오, 이번 달 수당이 좀 더 들어왔다" 정도의 미세 카타르시스.

### Q2. Daily Streak

- **Option B 찬성**. streak 표현은 *벽시계 도장*. "7일 출근 도장"은 *야근 누적이 아닌 정시 퇴근 누적*으로 톤 반전.
- 끊겨도 도장은 *흐려질 뿐*. 사라지지 않는다.

### Q6. Power-up 3종 — 톤

- 폭탄 = *해고 통지서* (한 부서 전체 사망 → 좀비 처치)
- 빙결 = *회의 무한정 연기* (좀비 시간 정지)
- 자석 = *사옥 자기장 폭주* (사원증 자기 신호 폭주 → 자석 효과)

### Q7. 카드 unlock 페이스

- Stage 3 누적 coin 게이트 시 *사옥의 새 영역이 칠해지는 0.8초 컷씬*. 텍스트는 1줄: "휴게실이 회복되었습니다" / "시간이 멈췄습니다" / "CEO 책상이 비었습니다".

## 비대칭 양보

- 카드명은 *수치 명확성을 위해 부제목*에 효과 명시 가능 ("양손 회수 — 데미지 +1"). 톤은 카드명에서, 정확성은 부제목에서.
