# Round 1 — Compulsion Architect

> 페르소나: 강박 아키텍트 (Compulsion Engine 설계자)
> 단계: Phase A-2 Meta + Juice 토론 / Round 1
> 입장 강도: 강 (Meta tree 페이싱 · Daily Streak 방향성에 강한 영향)

---

## 핵심 주장

**Meta tree와 Juice 카탈로그는 도파민 5단 구조(anticipation → effort → resolution → variable reward → next anticipation)를
60초 한 챕터 안에 *상한선까지* 채우되, 챕터 *밖*으로 새지 않도록 짜야 한다.** 메타가 매 챕터 안에서 보상을 부풀리면
flow zone이 깨지고, 메타가 챕터 *사이*에 갇히면 retention engine이 약해진다.

## 시드 질문별 입장

### Q1. Meta Tree 구조 — 15장 deck 분류

- **Damage / Crit% / PowerUp Duration / Coin Gain 4 base + Special 3장** 구조 *찬성*.
- 4 base는 *resolution* 단계에 즉시 체감, Special 3장은 *next anticipation*을 만든다.
  - Magnet Range: "다음에 한 번 더" 동기
  - Combo Decay Resistance: 직전 실패의 *복구 환상*
  - Critical Multiplier ×2 → ×2.5: 상위 보상의 *천장 인식*
- 시너지 v2는 **챕터 1~5 클리어율이 안정화된 시점 이후**. 데이터 없이 v1에 풀면 의사결정 비용으로 flow가 깨진다.

### Q2. Daily Streak

- **Option B (상승 보너스만)** *강력 찬성*.
- 강박 엔진의 원칙: *상실 회피*가 아닌 *접근 동기*. "끊길까 봐" 켜는 것은 게임이 사용자를 소유하는 패턴.
- 그러나 streak 자체 폐지(Option A)는 *지나친 무력화*. Day 1~7 시각화는 유지하되, 끊겨도 "어제 출근 보너스"만 사라지는 디자인.

### Q3. 가변 보상 Layer 2 범위

- **Option B (인테리어 + 골드 폭증, 카드는 결정론 풀)** *찬성*.
- 카드 가챠를 가변으로 풀면 *plays-to-extinction* 곡선이 생긴다. 카드 = 의사결정의 단위, 가변은 *환경*의 단위로 분리.
- 골드 폭증 1~3% × 5배는 매 챕터당 평균 0.5회 트리거 → 강박이 아닌 *서프라이즈*.

### Q4. 좀비 추상화 다이얼

- **Option B (50% 마스크)** *유지*. 손맛 곡선과 윤리적 거리감의 절충.

### Q5. Juice 카탈로그

- **freeze frame 0.6초**는 챕터 종료 *resolution beat*. 매 처치마다 freeze는 금지 — 카타르시스 인플레.
- hit-stop 4f(normal) / 6f(crit) / 8f(boss)는 도파민 강도와 정확히 비례.
- "팡!" 의성어는 *crit + combo 5+* 동시 조건에서만 노출. 남발 시 강박 진정제로 변질.

### Q6. Power-up drop rate

- **5% 기본 + 보스 처치 시 30% 확정** 찬성. 보스 처치의 *next anticipation* 강화.
- 메타 카드 Coin Gain Tier 3로 15%까지 상승하는 곡선은 *능동적 결정*이 보상으로 환원되는 구조 — compulsion이 아니라 mastery.

### Q7. 카드 unlock 페이스

- 첫 게임 4 base 풀, 챕터 5 클리어마다 Tier 2/3 unlock, Special은 누적 coin 1000/3000/10000 — *찬성*.
- 단, 누적 coin 표시는 *진행감*만 노출, *남은 거리*는 노출 금지 (loss aversion 유발).

## 비대칭 양보

Special 3장의 unlock 임계값(1000/3000/10000)은 *경험적*이라 v0.1 출시 후 데이터로 조정 가능 — 합의 1순위 항목.
