# Round 1 — Dark Pattern Critic

> 페르소나: 다크 패턴 비평가 (자율성·도박성·둔감화 감시자)
> 단계: Phase A-2 Meta + Juice 토론 / Round 1
> 입장 강도: **강 (ADR-0002/0003/0004 최종 결정자)**

---

## 핵심 주장

**Meta tree + Juice 카탈로그는 *접근 동기*만 강화하고 *상실 회피*는 만들지 않아야 한다.** 카드 unlock 곡선이 *FOMO 트리거*가 되거나
freeze frame 600ms가 *반복 강박*이 되거나 daily streak이 *끊길까봐* 켜는 행동이 되는 순간 모두 dark pattern. 가변 보상은
*제한*되어야 도박이 아닌 게임. 좀비 추상화는 *둔감화 임계*를 넘지 않아야 한다.

## 시드 질문별 입장 — ADR 결정

### ADR-0002. 가변 보상 Layer 2 범위 — **Option B 채택**

- **Option C/D 반대**. 카드 가챠 가변 + power-up 가변까지 결합되면 *60초 안에 3회 이상 가변 이벤트* → PGSI 모방 척도 임계 초과.
- **Option A 차선**. 골드 폭증 1~3% × 5배는 *간헐적 강화 스케줄* 안에 들어가지만, 빈도가 챕터당 평균 0.5회 → 도박 의존성 임계(2회 이상/세션) 미달.
- 따라서 **Option B**: 인테리어 + 골드 폭증. 카드는 결정론 풀에서 *플레이어가 빌드 계획 가능*.

> **사유 1줄**: 가변 빈도 챕터당 0.5회 = PGSI 임계 미달, 카드 결정론으로 빌드 자율성 보장.

### ADR-0003. Daily Streak 강도 — **Option B 채택**

- **Option D Hard Reset 강력 반대**. *상실 회피*는 dark pattern의 정의.
- **Option C Grace 1일 반대**. *grace*라는 명목이 "내일은 꼭 와야지"라는 강박을 *오히려 정교화*.
- **Option A 차선**. 그러나 코인 보너스 자체가 사라지면 retention 최소 동기마저 소실.
- 따라서 **Option B (상승 보너스만)**: "오늘 출근하면 +20% coin" 만. 끊겨도 *벽시계 도장이 흐려질 뿐*. 다음 출근 시 즉시 Day 1로 복귀(상실 아닌 리셋).

> **사유 1줄**: streak이 *접근 동기*로만 작동, *상실 회피* 0 — WHO 행동중독 분류 거리 최대 확보.

### ADR-0004. 좀비 추상화 다이얼 — **Option B 유지**

- **Option A (25%) 강력 반대**. 표정 있는 좀비 반복 처치는 폭력 정상화 임계 초과.
- **Option D (100%) 반대**. 완전 추상은 *대상의 정체성 소거* → 오히려 *모든 사람에게 폭력 가능*이라는 위험한 메시지.
- 따라서 **Option B (50% 마스크)**: 인간 형상은 유지하되 얼굴은 비어 있음. *직급(부서)*만 남고 *개인*은 익명 — 야근 메타포의 핵심.

> **사유 1줄**: 50% 마스크 = "처치 대상이 사람도, 추상도 아닌 *역할의 잔여물*"이라는 윤리적 절충점.

## 추가 Open ADR 권고

### ADR-0005 (신규 권고). Meta 카드 unlock 임계의 노출 방식

- "다음 unlock까지 N coin 남았다" 노출 = **FOMO 트리거**.
- 합의안: 진행 표시는 *상단 6px 가로 바*만. *남은 거리 숫자는 long-press 시에만 노출* (mobile-ux-pragmatist 동의).
- 이걸 ADR-0005로 박제 권고.

### ADR-0006 (신규 권고). Freeze frame 600ms의 알림 충돌

- 600ms 화면 정지가 *시스템 알림 / 전화*와 헷갈리면 *사용자가 게임이 멈춘 줄 알고 종료* 또는 *재실행 강박*.
- 합의안: 정지 중 *1px scale oscillation*으로 라이브 신호 (mobile-ux-pragmatist 제안 동의).
- ADR-0006으로 박제 권고.

## 시드 질문별 추가 입장

### Q1. Meta Tree 15장 — 윤리 검수

- Special 3장 중 **Critical Multiplier ×2 → ×2.5** = 누적 coin 10000 unlock → *최후 보상*.
- 이 임계가 *너무 멀어 보이면 무력감*, *너무 가까우면 강박*. 데이터 측정 후 조정 필수.
- 카드명 *사직서 한 방*은 톤이 통쾌하나, *반복 노출 시 회피 학습*. 컷씬은 1회만 표시 권고.

### Q5. Juice 카탈로그 — 윤리 검수

- *카운트다운 숫자 ("남은 시간 5초!")* 노출 금지 (core-loop consensus에서 합의됨, 재확인).
- "팡!" 의성어가 *crit + combo 5+ 동시 조건*에서만 노출되는 것 — *희소성 유지*. 남발 시 *진정제화* (compulsion-architect 동의).
- haptic 패턴 합계 200ms 한도 (mobile-ux-pragmatist 제안 동의). 그 이상은 *신체 통제권 침해 임계*.

### Q6. Power-up drop

- 5% + 보스 30% 확정 *조건부 찬성*. 단 *drop rate가 메타 unlock으로 곱셈으로 증가하면 슬롯머신화*.
- Coin Gain Tier 3 → 15% 상한 고정. *덧셈 누적 금지*.

### Q7. 카드 unlock 페이스

- 3-stage unlock (4 base 즉시 / 챕터 2·4 게이트 / 누적 coin 1000/3000/10000) *찬성*.
- 단 누적 coin 게이트는 *6주차·10주차*까지 끌고 가는 retention 도구. **10000 coin = 10주차**는 길다 → *데이터 보고 5000으로 축소 권고*.

## 비대칭 양보

- ADR-0005·0006은 *권고*이지 *합의 차단 조건*은 아님. 메디에이터가 합의 문서에 박제만 해도 충분.
- 10000 coin 임계는 *데이터 측정 후 조정 허용*.
