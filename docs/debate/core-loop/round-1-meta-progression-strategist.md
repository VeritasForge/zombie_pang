# Round 1 — meta-progression-strategist

> 페르소나 시점: 메타 카드 트리, 빌드 다양성, 장기 retention 곡선
> 입력: Phase A-0 — Layer 2 가변 보상 = 사옥 재건, 카드 트리 미정
> 출력: 5개 시드 질문에 대한 본인 답안

---

## 결론 한 줄

**MVP는 카드 트리 v1 = 단일 스탯**으로 출발. 단 *카드 = 부서·인테리어 이중 매핑*으로 v2 시너지의 발판을 깔아둔다.

---

## Q1. 단위 (세션/챕터/라운드)

세션 = 챕터 = 10층 = 60초 동의. 메타 진행 관점에서 한 세션 = 한 *progression beat*여야 한다. 더 작은 단위(층/라운드)에 메타 보상을 붙이면 *grind* 인식이 시작된다. 챕터 단위 보상은 **5번의 의미 있는 선택 = 한 런**이라는 단순한 멘탈 모델을 만든다. 50층 풀런 = 5 챕터 = 5장의 빌드 = *5분 안에 한 명의 사옥 완성*이라는 마이크로 + 매크로 사이클 결합이다.

## Q2. Layer 1/2 transition

여기가 메타 진행의 심장이다. **챕터 종료 후 정시 퇴근 화면에서 Layer 2 카드 1장 선택** — 동의. 단 카드 선택의 **이중 의미**를 살리자:

- **수치적 의미**: 다음 챕터의 stat boost (예: 처치 속도 +10%, 콤보 유지 시간 +0.5초)
- **세계관적 의미**: 사옥의 한 층 인테리어 변화 (예: "정수기" 카드 = 11~20층 휴게실 배치 → 다음 챕터 배경 변화)

이 이중 매핑이 핵심이다. 단일 스탯 부스트지만, **눈에 보이는 사옥이 바뀐다**. 메타 진행이 *숫자 인플레*가 아니라 *공간의 회복*으로 읽힌다. Layer 1은 결정론 유지, Layer 2는 가변 — 그 사이의 경계가 *transition UI에서 카드 = 인테리어 매핑*으로 가시화된다.

## Q3. CEO 보스 페이싱

마지막 5초 보스 동의. 메타 관점에서 보스는 **카드 unlock 트리거**여야 한다. 매 CEO 처치 = 다음 챕터에서 뽑을 수 있는 카드 풀에 1티어 추가. 즉:

- 10층 CEO 처치 → 카드 티어 1 (5종) 풀 활성화
- 20층 CEO 처치 → 티어 2 (5종) 추가
- 30층 CEO → 티어 3
- 40층 CEO → 티어 4 (legendary)
- 50층 CEO → 엔딩 + 메타 unlock (다음 런용 starting deck 선택권)

보스 = 메타의 게이트키퍼 구조. 매 챕터의 보스가 *그저 강한 적*이 아니라 *다음 가능성의 열쇠*가 된다.

## Q4. 카드 트리 깊이

**단일 스탯 부스트 위주 + deck 5장 + 3장 중 1장**. MVP 합당하다. 이유 3가지:

1. **콤보 시너지 v1 = 검증 안된 복잡도**. 의사결정 비용이 60초 페이싱을 깨먹는다.
2. **단일 스탯 5장도 빌드 다양성은 충분**: 5장 × 3장 중 1장 선택 = 3^5 = 243개 가능 빌드 (실질 변별력 있는 빌드는 ~40개).
3. **v2 시너지 콤보의 발판**: 카드 카테고리(공격/방어/콤보/특수/지원)를 미리 색 분류해두면, v2에서 "같은 색 3장 시 보너스" 같은 시너지 추가가 무비용.

장기 retention 곡선 측면에서, **첫 50층 클리어 = 약 25분**, 이후 *재플레이*는 다른 starting deck로 시도. 한 사용자에게 *3~5회 풀런 가치* = ~2시간의 코어 콘텐츠. MVP로는 충분.

## Q5. 정시 퇴근 버튼 위치

챕터 종료 직후 동의. 메타 진행 관점에서 *항상 노출*은 메타의 무게를 깎는다 — 매번 "그만둘 수 있다"고 상기되면 *진행의 의미*가 약해진다. 챕터 끝 = 메타 카드 선택 시점 = 정시 퇴근 옵션. **하나의 화면에서 "계속하기 + 카드 선택" 또는 "퇴근하기 + 이번 런 기록 저장"**의 명확한 양자택일. 메타 기록은 퇴근해도 보존되어야 한다 — 진행 손실 페널티 = 강박 트리거.
