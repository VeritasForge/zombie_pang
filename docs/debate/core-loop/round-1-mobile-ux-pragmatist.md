# Round 1 — mobile-ux-pragmatist

> 페르소나 시점: 한 손 portrait, thumb zone, 30초 세션 인터럽션 내성
> 입력: Phase A-0 — portrait 한 손, 30~60초 라운드, screen shake thumb zone 회피
> 출력: 5개 시드 질문에 대한 본인 답안

---

## 결론 한 줄

**60초가 한 손 모바일의 상한선**. 카드 선택 = 엄지 도달권 안에서, 정시 퇴근 = thumb-safe.

---

## Q1. 단위 (세션/챕터/라운드)

세션 = 챕터 = 10층 = 60초. 동의하지만 *모바일 인터럽션 통계* 관점에서 한 가지 강조:

- 평균 모바일 세션 = 1분 11초 (Statista 2024 캐주얼 게임)
- 출퇴근/엘리베이터/줄서기 = 30~90초 microsession이 압도적 다수
- 60초는 **"엘리베이터 한 번 = 한 챕터"** 의 황금 envelope다

단 **챕터 fail 시 자동 재시도 강요 금지**. 60초 챕터를 실패했을 때 *재도전 모달*이 즉시 떠야 한다 — 대중교통에서 화면 잠그면 *자동 일시정지*, 30분 이내 복귀 시 *resume*. 이 microsession 보호가 가장 큰 모바일 UX 자산이다.

## Q2. Layer 1/2 transition

챕터 종료 → 정시 퇴근 화면 → Layer 2 카드 1장 선택 → 다음 챕터. 동의. **transition UI에서 thumb zone 규칙 3가지**:

1. **카드 3장은 화면 하단 60% 영역**에 가로 배치 (엄지 자연 호 안)
2. **정시 퇴근 / 계속하기 버튼**은 화면 가장 아래 좌우 끝 = 한 손 엄지 baseline
3. **카드 자세히 보기 (탭) vs 선택 (long-press)** — 실수 방지

iOS notch / Android system bar 16dp safe-area는 transition UI에 *반드시* 반영. 챕터 끝 카타르시스가 시스템 제스처와 충돌하면 *그 챕터의 즐거움*이 통째로 죽는다.

## Q3. CEO 보스 페이싱

마지막 5초 보스, HP 게이지 표시 — 동의. 단 **HP 게이지 위치**가 결정적이다.

- 상단 = 안전, but 시선 이동 거리 큼
- 보스 머리 위 floating = 자연스럽지만 thumb으로 가림
- **권장: 화면 상단 1/6 영역, 좀비 sprite 위 + 상단 HP bar 2중 표시**

보스 페이즈 진입 시 진동 *짧은 펄스 1회*만. 5초 안에 진동 여러 번은 *손 떨림*과 구분 안 됨. screen shake도 5초 보스 페이즈에는 진폭을 평소(6px)에서 4px로 낮춘다 — HP 게이지 가독성 우선.

## Q4. 카드 트리 깊이

deck 5장 + 3장 중 1장 선택 — *모바일 UX에 최적*. 이유:

- 카드 5장 deck = 화면 한 줄에 표시 가능 (각 카드 ~64px 너비)
- 3장 중 1장 = 가로 배치, 각 카드 ~110px = 엄지 정확도 안 (Fitts's Law: 너비 ≥ 44dp 권장)
- 시너지 콤보 카드는 *카드 위에 추가 아이콘 + 작은 텍스트* 필요 → portrait 화면에서 가독성 폭락

**v2 시너지는 절대 MVP에 넣지 말 것**. 카드 정보 밀도가 portrait의 *글자 크기 한계*를 넘는다. 단일 스탯이 모바일에선 *기능적으로 옳다*.

## Q5. 정시 퇴근 버튼 위치

**챕터 종료 직후만**, 동의. 모바일 UX의 핵심 원칙: *intent-clear moment에만 보여줘라*. 5층마다는 thumb-tap 실수 유발 (게임 중 우발적 탭). 항상 노출은 화면 부동산 낭비 — portrait는 픽셀 한 줄이 귀하다.

**메뉴 안 퇴근 링크**는 햄버거 메뉴 안 *세번째 항목*에 텍스트로. 강조 색상 없음, 빨간색 절대 금지. 챕터 끝 정시 퇴근 모달은 **타이머 자동 dismiss 없음** — 사용자가 스스로 닫을 때까지 대기. 모바일에서 자동 dismiss는 *시간 압박 = dark pattern*이다.

추가: **백그라운드 진입 시 자동 일시정지**는 핵심 보호 장치. 60초 챕터가 30초 진행 후 백그라운드로 가도 안전 — 복귀 시 *남은 30초부터*. 이게 한 손 모바일의 인터럽션 내성을 만든다.
