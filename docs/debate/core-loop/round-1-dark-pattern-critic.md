# Round 1 — dark-pattern-critic

> 페르소나 시점: graceful exit 위치, FOMO 방지, 강박 트리거 감사
> 입력: Phase A-0 — graceful exit 챕터 종료, 5분 재접속 폐지, "출근 도장" 7일 후 강제 휴식
> 출력: 5개 시드 질문에 대한 본인 답안

---

## 결론 한 줄

**"챕터 종료 직후에만 정시 퇴근 노출"은 합의안의 가장 의심스러운 결정**이다. *graceful exit이 한 곳에만 있다면 그것은 더 이상 graceful이 아니다*. 박제할 ADR 후보.

---

## Q1. 단위 (세션/챕터/라운드)

60초 / 10층 / 한 챕터 단위 — 큰 반대는 없다. **단**: "한 세션 = 한 챕터"라는 등식이 *세션 길이의 하한선을 60초로 강제*하는 효과를 낳는다는 점을 짚어둔다.

- 사용자가 30초 시점에서 *그만두고 싶다*면? 챕터 fail 처리로만 가능 → "실패"라는 부정적 프레이밍.
- 정상적 중단 = 챕터 종료 = 보스 처치 완료 = 60초 풀 플레이. **이건 강제된 60초**다.

대안: 챕터 시작 시점에서 **"오늘 그만하기" 버튼**을 메인 메뉴에 동등한 격으로 두기. 한 챕터를 *반드시* 끝내야 한다는 압박을 풀어주는 안전판이 필요하다.

## Q2. Layer 1/2 transition

챕터 끝 카드 1장 선택 — 동의하되 **dark pattern 리스크**:

- 카드 선택이 *반드시 다음 챕터로 이어진다*면, 사용자는 *카드를 봤기 때문에 멈출 수 없다*. 매몰비용 편향 트리거.
- 권장: 카드 *선택 직후*에도 "정시 퇴근" 버튼이 *동일 가중치*로 표시되어야 한다. "**카드를 골랐어도 퇴근하고 다음에 쓸 수 있다**" — 카드는 *보존된다*.

이렇게 하면 카드 = 매몰비용 트리거에서 *예치된 자산*으로 의미가 바뀐다. 강박은 *손실 회피*에서 시작된다. 카드 보존은 *손실 없음*을 명시한다.

## Q3. CEO 보스 페이싱

마지막 5초 보스, HP 게이지 — 큰 문제 없음. **하나만**: 보스 처치 직전 *0.5초 카운트다운 위협*은 절대 넣지 말 것. "남은 시간 5초!" 식의 압박 텍스트는 *artificial urgency*. 보스 자체의 위협으로 충분하다.

## Q4. 카드 트리 깊이

단일 스탯, deck 5장, 3장 중 1장 — 동의. **dark pattern 감사 통과**. 콤보 시너지 v2 미루기 결정은 *분석 마비 회피*뿐 아니라 *변동 비율 강도 완화*의 의미도 있다. 시너지가 있으면 *완벽한 빌드*를 노리는 *재플레이 강박*이 생긴다. 단일 스탯은 *충분히 좋음*의 안정점에 빠르게 도달 → 그만두기 쉽다.

**추가 권고**: 카드 풀 unlock이 *영구 메타*가 되면 강박이 생긴다. **카드 unlock은 한 런 안에서만 누적**, 런 끝나면 starting deck로 리셋. *Hades*가 한 일이다. 영구 메타가 가벼울수록 *그만두기*도 가볍다.

## Q5. 정시 퇴근 버튼 위치 — **가장 위험한 결정**

권장 결정 "**챕터 종료 직후에만 노출**"에 **부분 반대**.

근거:

1. **챕터 종료 = 도파민 최고점**. 이 시점에 "퇴근"은 *심리적으로 가장 어려운 선택*이다. graceful exit는 *어려운 곳*에만 두면 안 된다.
2. **5층마다 노출 = 의사결정 피로**라는 주장은 *실증 미상*. 오히려 *언제든 멈출 수 있다는 안정감*이 retention에 긍정적일 수 있다 (Apple Screen Time UX 사례).
3. **menu 안 비강조 텍스트 링크**는 *숨김*과 *접근성*의 경계에서 미묘하게 dark pattern 쪽이다. *클릭 한 번에 닿는 graceful exit*가 윤리적 기준선.

**수정 권장안**:

- **챕터 종료 직후 노출 = 메인 강조**
- **게임 중 일시정지 메뉴 안 = 동등한 가중치의 "퇴근하기" 버튼** (회색 텍스트 아님, 일반 버튼)
- **챕터 시작 직전 = "오늘 그만하기" 옵션** (다음 챕터 들어가기 전 마지막 안전판)

세 지점이 *모두 동등하게* 접근 가능해야 한다. 그것이 진짜 graceful이다.

**ADR 박제 권고**: 본 결정은 합의로 채택되더라도 *Open ADR로 박제*하고, MVP 출시 후 사용량 데이터 (퇴근 버튼 클릭 위치 분포)로 재검증할 것. *측정 후 수정 가능한 결정*임을 명시해야 한다.
