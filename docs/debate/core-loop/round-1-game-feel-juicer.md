# Round 1 — game-feel-juicer

> 페르소나 시점: 손맛, hit-stop, transition feel, juice 밀도
> 입력: Phase A-0 — 0.4초 손맛 루프, Phaser Graphics 추상화, "팡!" 의성어
> 출력: 5개 시드 질문에 대한 본인 답안

---

## 결론 한 줄

**transition feel은 게임의 척추**다. 챕터 끝 0.6초가 60초보다 강렬해야 다음 챕터를 켠다.

---

## Q1. 단위 (세션/챕터/라운드)

60초 / 10층 / 한 세션 한 챕터에 동의. 이유는 *juice density*다. 한 라운드 = 한 층이면 0.4초 손맛 루프 × 10회 + 챕터 종료 페이즈 1회 = **약 50~55초의 액션 + 5~10초의 카타르시스**. 비율로 보면 85% 액션 / 15% 보상인데, 이건 *Vampire Survivors*의 30분 세션을 60초로 압축한 골든 레이시오다. 30초 챕터는 juice가 들어갈 자리가 없다. 60초가 *minimum viable juice envelope*다.

## Q2. Layer 1/2 transition

여기가 가장 중요하다. **transition 자체가 reward feel의 80%를 좌우한다**.

- 챕터 종료 0초: 보스 처치 → freeze frame 0.6초, 화면 desaturate, "팡!" SFX 한 번 더 길게 (1.2초 리버브)
- 0.6초~1.2초: 카메라 줌아웃, 사옥 외관 실루엣 등장, 한 층 색이 채워짐 (Layer 2 시각화 = *너의 노동의 결과*)
- 1.2초~: "정시 퇴근" 모달 + 카드 3장 fan-out 애니메이션 (각 카드 0.15초 stagger)

이 transition을 *cinematic moment*로 만들면 카드 1장이 카드 3장처럼 느껴진다. **느낌의 깊이가 의사결정의 깊이를 대체**한다. juice 예산은 이 1.5초 구간에 전체의 30%를 쏟아도 된다.

## Q3. CEO 보스 페이싱

마지막 5초 보스 페이즈 — 좋다. 단 5초는 **3 phase**로 잘게 자른다.

- **0.0~1.0초 telegraph**: 화면 셰이크 진폭 8px, 빨간 비네팅, "이번 분기…" 자막
- **1.0~4.0초 engagement**: HP 게이지 3등분 (1/3 깎을 때마다 색 변화 + 콤보 SFX)
- **4.0~5.0초 climax**: 마지막 1/3 HP에서 슬로우모션 0.3배속, 처치 시 freeze + 사원증 폭발 32 파티클

5초 안에 이 3-phase 구조가 있어야 보스가 "그냥 강한 좀비"가 아닌 *서사의 정점*으로 느껴진다.

## Q4. 카드 트리 깊이

단일 스탯 부스트 + deck 5장 동의. 단 **카드 뽑힘 애니메이션**에 사치를 부린다. 카드 한 장이 등장할 때 종이 펄럭이는 사운드, 약간의 회전 (Y축 12도), 그림자 깊이, 선택 시 "결재" 도장 SFX + 빨간 도장 파티클. 의사결정 깊이를 *연출 깊이*로 보상한다. 시너지 콤보 v2 동의 — MVP에서 화려한 카드 1장이 평범한 카드 3장의 시너지보다 손맛이 좋다.

## Q5. 정시 퇴근 버튼 위치

챕터 종료 직후 동의. transition feel을 살리려면 *항상 노출*은 절대 금지 — UI 노이즈가 손맛을 죽인다. 챕터 끝에서만 **2.0초 ease-out으로 fade-in**, 게임 중 menu 안에서는 *작고 회색의 텍스트 링크* — 강조도 숨김도 아닌 중립 형식. 퇴근 선택지 자체에도 juice가 필요하다: 선택 시 *책상 정리 SFX + 사무실 불 꺼지는 트랜지션*. 끝나는 것조차 손맛이다.
