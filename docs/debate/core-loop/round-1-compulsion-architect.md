# Round 1 — compulsion-architect

> 페르소나 시점: variable ratio dopamine, 강박 루프 설계
> 입력: Phase A-0 consensus (50층 좀비 사옥, 10층 챕터, 30~60초 라운드, Layer 1 결정론 / Layer 2 가변)
> 출력: 5개 시드 질문에 대한 본인 답안

---

## 결론 한 줄

**한 챕터 = 한 도파민 사이클**로 설계하고, 가변 보상은 **챕터 끝 단 1지점**에 응축한다. 분산은 강박을 만든다.

---

## Q1. 단위 (세션/챕터/라운드)

세션 = 챕터 = 10층 = 60초. 이게 옳다. 도파민 사이클은 **anticipation → effort → resolution → variable reward → next anticipation**의 5단 구조인데, 30초 안에 10층을 다 넣으면 anticipation을 만들 시간이 없다. **60초 / 10층 / 보스 5초 포함**이면 1층당 5.5초, 마지막 5초 보스 페이즈에 진폭이 잡힌다. 한 세션 안에 *작은 결정론 사이클 10개 + 큰 가변 보상 1개*가 들어가는 이 비율이 핵심이다.

## Q2. Layer 1/2 transition

**챕터 종료 즉시 정시 퇴근 화면에서 Layer 2 카드 1장**. 이건 행동 분석학적으로 옳다. Layer 1(결정론) 안에서 가변 보상을 섞으면 *plays-to-extinction 곡선*이 형성되어 강박 루프가 시작된다. 챕터 단위로 **에피소드 컷**을 명확히 끊고, 그 끝에서만 가변을 허용해야 *flow*가 *grind*로 변질되지 않는다. 카드 1장 — 3장 중 1장 선택 — 이 의사결정의 최저 하한이다. 0장은 보상 없음이라 anticipation이 죽고, 2장 이상은 분석 마비.

## Q3. CEO 보스 페이싱

매 챕터 마지막 5초 보스 페이즈, HP 게이지 표시. 이건 *"build → release"* 도파민 구조 그대로다. 9층까지 누적된 텐션이 10층 진입 순간 보스 등장으로 해소된다. 단, 보스 처치 = 챕터 종료 = 정시 퇴근 선택의 **3중 결합**은 위험하다. 보스 처치 직후 0.6초 freeze frame을 넣어 *"네가 해냈다"* 감각을 만들고, 그 뒤에 퇴근 선택지를 노출한다. 결합 시점을 0.6초만큼 분리해야 강박이 아닌 성취감으로 읽힌다.

## Q4. 카드 트리 깊이

**단일 스탯 부스트 / deck 5장 / 3장 중 1장 선택**. 시너지 콤보는 v2로 미룬다. MVP 단계에서 콤보를 넣으면 의사결정 비용이 60초 페이싱을 깨먹는다. 변형은 **카드 카테고리의 색감만 다양화**해서 *체감 다양성*을 만든다 (예: 정수기·복합기·자판기 인테리어). 가변 보상의 핵심은 *실제 다양성*이 아니라 *지각된 다양성*이다.

## Q5. 정시 퇴근 버튼 위치

**챕터 종료 직후에만 노출 + 게임 중 menu 진입 시 비강조**. 5층마다 노출은 의사결정 피로다. 항상 노출은 게임 몰입을 깬다. 챕터 끝에만 노출하되, 메뉴 안에 "퇴근하기"를 *조용한 텍스트 링크*로 둔다. graceful exit는 강조하지 않을수록 윤리적이다 — 강조하면 그 자체가 *"퇴근 안 하면 손해"*의 dark pattern이 된다.
