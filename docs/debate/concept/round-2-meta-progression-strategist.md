## 1. 대결 페르소나 비판 — #2 game-feel-juicer의 "0.4초 손맛"이 meta 깊이를 잠식하는 방식

게임 필 주서(juicer)는 "B급 코믹 호러 + 0.4초 손맛"으로 즉각 도파민을 설계했다. 손맛 자체는 게임의 입구로서 필수적이지만, **즉시 보상 강도가 너무 높으면 meta loop의 장기 동기를 압도한다.** 이를 "도파민 인플레이션" 문제로 부른다.

- **신경경제학적 함정**: 0.4초 단위 자극은 도파민 phasic 분비를 유발한다. 반면 meta progression(방주 시설 1단계 업그레이드)은 5~10분 후 효과가 나타나는 tonic 보상이다. phasic이 과강할수록 tonic 보상의 perceived value는 상대적으로 줄어든다. **"팡! 팡! 팡!"이 너무 즐거우면 "방주가 풍부해진다"는 의미가 silent해진다.**
- **구체적 침식 시나리오**: 플레이어가 60초 런에서 200마리를 0.4초 손맛으로 처치한다 → "기억 단편 12개 회수"라는 meta 보상 텍스트가 화면에 뜬다 → 플레이어는 X 버튼을 누르고 다음 런으로 직행한다. **meta 텍스트가 손맛의 잔향에 묻혀 읽히지 않는다.**
- **B급 코믹 톤의 위협**: "비통한 코미디"가 아닌 "B급 코믹"은 좀비=기억상실자 서사를 농담거리로 격하시킨다. "기록 보관자"의 도덕적 무게가 슬랩스틱에 잠식되면, daily streak 미스의 "기억 영구 소실" 페널티가 진지하게 받아들여지지 않는다.

**해결 방향**: 손맛은 유지하되, 처치 후 **0.8초의 "기억 흡수" 잔향 모션**을 추가하여 phasic→tonic 전이 구간을 만든다. 손맛의 끝이 meta의 시작이 되도록.

## 2. 다른 5명 평가 — Meta 시스템 적합도

| # | 페르소나 | Meta 적합도 | 평가 |
|---|---------|----------|------|
| 1 | compulsion-architect | 상 | 가변 비율 재료는 카드 시너지와 직결. 베이커리 레시피 = 생존자 덱과 동형. **융합 1순위.** |
| 3 | difficulty-balancer | 중상 | "백신 농도"는 L1 시설 트리에 흡수 가능. Wave 10 도달률 85%는 meta 보상 페이싱 기준치로 차용. |
| 5 | mobile-ux-pragmatist | 중 | "한 손 30초"가 meta 화면 진입 동선을 압박. 단, **세션 길이 30초가 daily streak의 최적 진입점**이라는 점은 호환적. |
| 6 | narrative-thematist | **최상** | 사무실 번아웃 = "회사라는 방주", 동료 = 생존자 카드. 결합 시너지 폭발적. **하단 4번에서 상세 융합.** |
| 7 | dark-pattern-critic | 상 | sleep-friendly · "추상 잡념"은 daily streak FOMO를 완화하는 ethical guard. 내 안의 "기억 영구 소실" 페널티가 dark pattern으로 비치지 않도록 조정 필수. |

특히 **#6 사무실 좀비의 회사 위계는 meta 카드 트리에 그대로 매핑된다**: 사원→대리→과장→부장의 직급 체인이 카드 진화 트리가 되고, 부서(개발/영업/인사)가 시너지 태그가 된다. 좀비화된 동료를 "기억 회수"하여 책상에 복귀시키는 행위가 곧 방주 재건이다. 서사·UI·meta가 한 축으로 정렬된다.

## 3. 자기 수정 — Round 1 "방주" 컨셉의 mobile 첫 30초 무게

솔직히 인정한다. **3-Layer meta(방주 시설 + 생존자 Codex + Daily 송신)는 첫 30초에 노출되면 압살적이다.** mobile-ux-pragmatist의 한 손 30초 기준에 정면 충돌한다.

**단순화 안 — "Progressive Meta Disclosure (PMD)"**:

| 시점 | 노출 레이어 | 화면 요소 |
|-----|----------|---------|
| Run 1~3 (0~5분) | 손맛 only | meta UI 완전 숨김 |
| Run 4 (~7분) | L1 단편 1개 | "방주에 첫 기억이 도착했다" 1줄 토스트 |
| Run 10 (~20분) | L2 카드 1장 | 첫 NPC 구출 컷씬 (skip 가능) |
| Day 2 | L3 daily | 라디오 송신 도착 알림 |

핵심은 **"방주"라는 무거운 메타포를 첫 화면에 노출하지 않는 것**이다. 플레이어는 처음에 "팡!"만 즐기다가, 시스템이 점진적으로 의미의 깊이를 풀어준다. **방주는 발견되는 것이지 강요되는 것이 아니다.**

## 4. 융합 제안 — "회사 방주(Corporate Ark)": 사무실 좀비 + 부서/직급 meta tree

**#6 + #4 hybrid 컨셉**:

- **세계관**: 플레이어는 야근 중 회사 전체가 좀비화된 IT 회사의 마지막 사원. 회사 서버실이 곧 "방주", 동료들의 사원증 데이터가 곧 "기억 코어"다.
- **L1 (방주 시설) → 사무 공간 재건**: 정수기·복합기·회의실 해금. 각 시설이 패시브 효과 제공. "탕비실 레벨 3"이 곧 데미지 +5%.
- **L2 (생존자 Codex) → 부서/직급 카드 트리**:

```
[사원] → [대리] → [과장] → [부장] → [임원]
  ↓        ↓        ↓        ↓        ↓
개발팀   영업팀   인사팀   재무팀   전략팀  (시너지 태그)
```

  - 같은 부서 3장 = 부서 시너지 발동
  - 같은 직급 라인 = 직급 콤보 (예: 과장×3 → "결재 폭격")
- **L3 (Daily) → "월요일 회의 소집"**: 매주 월요일 9시에 특별 시드 활성. streak 끊기면 "프로젝트 마일스톤 1개 영구 소실".
- **톤 조율**: B급 슬랩스틱이 아닌 **#6의 "비통한 코미디"** 로 정렬. "결재판으로 부장 좀비를 후려치는" 행위가 동시에 웃기고 슬프도록.
- **dark-pattern-critic 가드 통합**: daily 미스 페널티는 "기억 영구 소실"이 아닌 "재발급 가능하나 비용 발생"으로 완화. sleep-friendly.

이 융합은 **친숙도(직장)·서사 깊이(번아웃)·meta 구조(직급 트리)·mobile UX(30초 출근 미션)** 가 한 점에서 만나는 지점이다. 한 손 30초의 "엘리베이터 옥상까지"가 곧 "퇴근까지 한 층씩"이 된다.
