## 1. 최종 합의 컨셉 (Single Statement)

> **"당신은 마지막 사원이다. 50층 좀비 사옥에서 야근을 끝내고 옥상까지 올라가 퇴근하라."**

좀비팡은 *번아웃이 물리적으로 발현된 직장*을 무대로, **한 손 30초 세션 안에서 한 층씩 올라가는 수직 진행 캐주얼 액션**이다. 톤은 **B급 코믹 호러**, 무게추는 **번아웃 풍자**, 출구는 **명시적 "정시 퇴근"**. 좀비를 "죽이는" 게임이 아니라 동료를 **"퇴근시키는"** 게임이다.

코드네임: **퇴근팡 (Off-Clock Pang)** — dark-pattern-critic이 Round 2에서 제안하고 다수가 양가적이지만 수용한 안.

## 2. 세계관 설정 — 50층 좀비 사옥

- **공간**: 정체불명의 다국적 IT 회사가 입주한 **50층 사옥**. 사옥 자체가 던전이고, 한 층이 하나의 Wave다. CEO가 **"무기한 야근 명령"**을 내린 뒤 전 사원이 좀비화됐다.
- **사건**: 좀비 바이러스의 정체는 **번아웃의 물질화**. 회의·KPI·결재·야근이 임계점을 넘으면 동료가 좀비로 변한다. 학술 알리바이로 **WHO 2019 번아웃 직업현상 분류** 인용.
- **톤**: **B급 코믹 호러**. 네온 핑크/라임 그린 + "비통한 코미디(melancholic slapstick)"의 교집합. *Plants vs Zombies와 Inside 사이 어딘가, Mike Judge의 Office Space에 더 가까운 자리*.
- **글로벌 추상화**: 한국 위계어("부장님") 대신 **글로벌 오피스 클리셰**(후디·헤드셋·명찰·키보드·결재판). 텍스트 0줄로도 좀비 등급을 알아볼 수 있게 의상·실루엣 도상화.
- **사옥 구조**: 50층을 한 세션에 클리어하지 않는다. **10층 1챕터 × 5챕터**로 끊고, 챕터 종료 시 "정시 퇴근" 선택지 제공.

## 3. 플레이어 정체성 & 동기

- **이름 없음, 사번만 있음**: `EMP-0427`. 캐릭터는 *야근 중 우연히 살아남은 마지막 정상인*.
- **무기**: 마우스·키보드·스테이플러·정수기 통·결재판. 모두 사무 비품. 총·도검 0개 — 폭력 둔감화 리스크 회피.
- **동기**: 좀비를 **"치료"하는 것이 아니라 "정신차리게 만드는"** 톡(tap)이다. 처치 시 사원증 1장이 떨어지고, 화면 구석에 **"수고하셨습니다 — EMP-0xxxx 퇴근"**이 작게 뜬다.
- **승리 조건**: 50층 옥상에 도달해 **사직서를 제출**한다. 엔딩은 "전직"이 아니라 **"퇴직"** — 좀비팡은 *끝나는 게임*이다.

## 4. 좀비 4종 디자인 (회사 위계 → 글로벌 추상화)

| Emoji | 명칭 (한/EN) | 직급 메타포 | 속도 / HP | 시그니처 | Phaser Graphics 표현 |
|---|---|---|---|---|---|
| 🧟 | 신입 / Intern | 갓 감염, 인간성 잔재 | 빠름 / 약함 | 비뚤어진 사원증, 한쪽 신발 | 작은 원 + 흔들리는 명찰 사각형 |
| 🧟‍♂️ | 과장 / Middle | 책임감에 짓눌림 | 중간 / 중간 | 늘어진 넥타이, 서류 뭉치 | 중간 사각형 + 흩날리는 종이 파티클 |
| 🧟‍♀️ | 팀장 / Lead | 회의를 끝내지 못한 자 | 느림 / 강함 | 깨진 안경, 식은 머그컵 | 큰 사각형 + 분노 게이지 링 |
| 🧠 | CEO / Founder Zero | 바이러스의 근원, 회사 그 자체 | 보스 (10층마다) | 몸 없이 뇌만, KPI 그래프 후광 | 거대 원 + Graphics 후광 + 차트 폴리곤 |

- **표현 제약**: 모두 **Phaser Graphics**(원·사각형·다각형)로만 그린다 — 아트 에셋 0개, MVP 빠른 개발 가능.
- **얼굴 없음 / 마스크 처리**: *유기적 실루엣 + 표정 없는 마스크* (약 50% 추상화 다이얼).
- **위계 = 난이도 곡선**: 신입→과장→팀장→CEO는 Tier 1~4, "회사 위계 = 비극의 단계"가 그대로 difficulty signal로 작동.
- **CEO 보스 패턴**: 매 10층(10·20·30·40·50)에 등장. 마지막 CEO(50층)는 **"이번 분기 KPI…"** 대사 후 사직서로 처치.

## 5. Compulsion vs Ethics 균형

| 항목 | 합의안 |

| **30초 라운드** | 유지 (한 손 30~60초). 즉시 재시작 버튼 + 강박 트리거 결합 금지 |
| **Graceful Exit** | 매 챕터(10층) 종료 시 **"정시 퇴근" 버튼**. 계속 / 퇴근 / 내일 모드 3택 |
| **가변 비율 보상** | *Layer 2 보상*(사옥 인테리어 재건)에만 한정. *Layer 1*(좀비 처치)은 **결정론적** |
| **Daily Streak** | "**출근 도장**"으로 리브랜딩, **7일 후 자동 휴식 강제** ("연차 사용") |
| **5분 재접속 강제** | **폐지**. 푸시 알림 없음, FOMO 카피 없음 |
| **광고/가챠** | Open Issue → ADR-0001로 박제 |
| **수면 친화** | 자정 이후 첫 실행 시 "오늘은 충분히 했어요" cue + 화면 자동 야간 모드 |
| **F2P/수익화** | MVP는 일회성 풀언락 가정, 라이브 BM은 Phase B에서 재논의 |

## 6. Game Feel 톤 결정

- **B급 코믹 호러** 확정. 진지 호러·카와이·미니멀 추상 기각.
- **0.4초 손맛 루프**: hit-stop 4프레임 → screen shake (진폭 6px, 감쇠 0.85) → flash white 1프레임 → 파티클 폭발 → 4-layer SFX → aftermath 숫자 팝업.
- **Adaptive Particle Degradation**: 24 → 12 → 6단계, thermal state·fps 기반 자동 감소.
- **Screen shake는 thumb zone 침범 시 진폭 6→3px로 자동 감쇠**.
- **Haptic은 콤보 5+ / 보스 처치 / wave clear 3개 이벤트로 한정**.
- **"팡!" 의성어 사운드 강조**: 한국어 의성어 미학으로 튜닝, 글로벌 출시 시에도 음역 그대로.
- **파티클 비주얼**: 피·살점 대신 **사원증·종이 파편·커피 스플래시·USB 메모리**.
