# Round 1: Meta-Progression Strategist 제안

> 페르소나 #4 · 영구 업그레이드, daily streak, 카드 시스템, 의사결정 깊이 전문가

---

## 1. 제안

**핵심 컨셉**: "마지막 방주의 기록 보관자(The Last Ark Archivist)" — 플레이어는 좀비 아포칼립스 이후 인류의 마지막 데이터 방주를 지키는 **기록 보관자(Archivist)** 다. 매 런(run)은 외부 폐허로 나가 잃어버린 "기억 코어(Memory Core)"를 회수하는 원정이며, 죽어도 회수된 기억 일부가 방주에 영구히 각인된다.

**3-Layer Meta Progression 구조**:

| 레이어 | 영구 자원 | 동기 부여 | 의사결정 깊이 |
|-------|---------|---------|-------------|
| **L1: 방주 시설(Ark Facilities)** | 기억 단편(Memory Shards) | "다음 런이 더 강해진다" | 시설 트리 분기 선택 |
| **L2: 생존자 카드(Survivor Codex)** | 구출한 NPC = 카드 | "누구를 살릴 것인가" | 덱 빌딩, 시너지 조합 |
| **L3: 일일 송신(Daily Broadcast)** | 라디오 신호 streak | "오늘 들어야 할 이유" | 매일 다른 시드의 변형 룰 |

**좀비의 본질 재정의**: 좀비는 단순 적이 아니라 **"기억을 잃은 인류 그 자체"** 다. 처치한 좀비에서 추출하는 것은 시체가 아닌 **단편화된 기억**이다. 이 narrative는 모든 meta loop의 동기와 정당화를 동시에 제공한다.

**Daily Streak Hook**: "방주 외부 안테나는 매일 24시간마다 새로운 좀비 무리 좌표를 송신한다. 송신을 놓치면 그날의 기억은 영원히 소실된다." → 미스 페널티가 서사적으로 정당화됨.

## 2. 근거

### 2.1 왜 "기록 보관자"인가? (정체성 ↔ Meta loop 결합)

**Slay the Spire**의 성공 비결은 카드 1장이 단순 자원이 아닌 **"내가 누구인지"** 의 표현이라는 점이다. 좀비팡도 마찬가지로, 플레이어 정체성이 **"수집·보관·기록"** 일 때 영구 업그레이드가 자연스럽게 정당화된다.

- 캐릭터가 "전사"라면 → 왜 죽고도 무기가 영구 강화되는가? **서사 공백 발생**
- 캐릭터가 "기록 보관자"라면 → 한 번 기록된 기억은 영원히 남는다. **서사 = 시스템**

### 2.2 좀비 = 기억 상실자라는 재해석의 힘

**Hades**가 위대한 이유는 죽음(=실패)이 서사적으로 정당화되기 때문이다(자그레우스는 죽지 않고 돌아온다). 좀비팡에서도 좀비를 단순 "쏘는 표적"이 아닌 **"되찾아야 할 인류의 조각"** 으로 정의하면:

- 처치 = 약탈이 아닌 **회복(recovery)** 행위 → 도덕적 부담 제거
- 좀비 한 마리 = 잠재적 기억 1조각 → 모든 적 처치에 meta 가치 부여
- "수백 마리를 팡!" 이라는 양적 쾌감이 "수백 개의 기억을 되찾았다"는 질적 의미로 전환

### 2.3 Daily Streak의 서사적 정당화

**Vampire Survivors**의 약점은 daily가 단순 "오늘 미션" 수준이라는 것이다. 좀비팡은 다음과 같이 정당화한다:

```
[방주 라디오 안테나] —— 24h 주기 ——> [외부 좀비 무리 좌표]
        ↓                                      ↓
   놓치면 신호 소실                   잡으면 daily seed 활성
        ↓                                      ↓
   "기억의 영구 소실"                  "streak 보너스 카드"
```

이 구조에서 streak이 끊기는 것은 단순 UX 페널티가 아닌 **"인류의 기억 일부가 영원히 사라졌다"** 는 서사적 비용으로 작동한다. FOMO(Fear of Missing Out)가 정당화된다.

### 2.4 의사결정 깊이: 3-Layer가 만드는 trade-off

| 런 종료 시 선택 | trade-off |
|---------------|----------|
| 기억 단편 → 방주 시설 vs 생존자 카드 강화 | 즉시 파워 vs 장기 시너지 |
| 같은 NPC를 한 번 더 구출 vs 새 NPC 시도 | 안정성 vs 다양성 |
| Daily streak 유지 vs 본 런 집중 | 의무감 vs 자유도 |

**선택의 의미**가 매 런마다 발생하므로, "그냥 클릭만 하는 영구 업그레이드"의 함정에 빠지지 않는다.

### 2.5 페르소나 #2(game-feel-juicer)에 대한 사전 반박

손맛만으로는 retention이 무너진다. **Vampire Survivors의 D30 retention이 D7의 절반 이하**로 떨어지는 이유는 meta loop의 서사적 무게가 부족하기 때문이다. "팡!"의 쾌감은 입구이지만, 30일 후에도 돌아오게 만드는 것은 **"내 방주가 어제보다 풍부해졌다"** 는 누적된 의미감이다.

## 3. 대안 기각 이유

### 3.1 "단순 좀비 슈터 + skill tree" 기각

흔한 talent tree는 노드 해금이 곧 끝이다. 노드 자체에 **서사가 없으면** 플레이어는 "+5% 데미지"를 외우지 못한다. 방주 시설 트리는 각 시설이 NPC 회복·구출 가능 인원·기억 해독 속도 등 **서사 단위**로 표현되어야 한다.

### 3.2 "주인공이 전사·군인" 컨셉 기각

전형적 좀비물 주인공은 meta progression의 서사 공백을 만든다. 죽은 군인이 어떻게 다음 런에서 더 강해지는가? 반면 "기록 보관자"는 **죽음조차 데이터 회수의 일부**로 흡수한다.

### 3.3 "Daily quest = 단순 미션 리스트" 기각

Daily가 "오늘 좀비 100마리 처치" 수준이면 서사 무게가 0이다. 안테나 송신·신호 소실이라는 **시간 종속적 서사 장치**가 있어야 streak이 도덕적·정서적 비용을 동반한다.

### 3.4 "카드 시스템 없이 영구 무기 강화만" 기각

무기만 영구화하면 의사결정 깊이가 1차원이다. 생존자 카드(Codex)는 **"누구를 구할 것인가"** 라는 윤리적 선택을 게임 메커닉으로 환산하여, 매 런마다 새로운 의사결정 축을 만든다.
