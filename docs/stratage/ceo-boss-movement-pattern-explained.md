## 3. 결정론 (Determinism)

**정의**: 같은 입력(seed)으로 시작하면 결과가 정확히 동일한 게임 로직.

**좀비팡에서의 강제** (CLAUDE.md §8 Rule #6, Bible §7):
- `Math.random()` 금지 → `IRandom` Port 주입 (seed 제어)
- `Date.now()` 금지 → `IClock` Port 주입 (시간 조작 가능)
- `setTimeout` 금지

**왜 중요한가**: property-based test (`seed=42, numRuns=1000`)와 회귀 테스트가 가능.

**각 패턴의 결정론 친화도**:

| 패턴 | 친화도 | 이유 |
|------|--------|------|
| 8자 궤도 | ⭐⭐⭐⭐⭐ | sin(t) — 시간만 알면 결과 100% 동일 |
| 좌우 Patrol | ⭐⭐⭐⭐⭐ | sin과 동일 |
| 하이브리드(텔레포트) | ⭐⭐⭐⭐ | IRandom으로 다음 위치 결정 → seed 같으면 같음 |
| 회피 대시 | ⭐⭐ | 사용자 탭 입력 자체를 timing+위치까지 기록해야 재현 가능 |

## 4. Ethics (윤리적 게임 디자인)

**정의**: 게임이 사용자를 강박/좌절/조급증으로 끌어들이지 않는다는 약속 (Bible §7, ADR-0006).

**Bible §7 10대 안티패턴 요약**:

| # | 안티패턴 | 좀비팡 방침 |
|---|---------|-------------|
| 1 | Streak 끊김 페널티 | 금지 (도장은 흐려질 뿐) |
| 2 | Notification 권한 요청 | 영구 비요청 |
| 3 | Energy/Stamina 시스템 | 금지 |
| 4 | 가챠 정량 표기 ("15%") | 금지 |
| 5 | 무한 retention | 금지 |
| 6 | 카운트다운 압박 텍스트 | 금지 |
| 7 | 외부 광고 | 금지 |
| 8 | 카드 가챠 가변 확률 | 금지 |
| 9 | streak 끊김 alarm | 금지 |
| 10 | carrot/stick 강박 | 금지 |

**각 패턴의 Ethics 위험**:

| 패턴 | 위험 | 어떻게? |
|------|-----|--------|
| 8자 | ✅ 안전 | 예측 가능 = 학습 가능 = 좌절 없음 |
| Patrol | ✅ 안전 | 가장 명확 |
| 텔레포트 | ⚠️ #4 슬롯머신화 비슷 | "운에 따라 잡냐 못 잡냐" |
| 회피 대시 | ⚠️ #10 carrot/stick | "탭했는데 회피당함" → 좌절감 → 강박 패턴 |

## 5. 트레이드오프 (Trade-off)

**정의**: 모든 디자인 결정은 뭔가를 얻으면 뭔가를 잃는다. 양손에 다 들 수 없는 상황.

| 패턴 | 얻는 것 | 잃는 것 |
|------|--------|---------|
| 8자 | 매력적 비주얼 + 학습 재미 | 초반 약간 어려움 |
| Patrol | 단순함 + 즉시 이해 | 단조로움 |
| 하이브리드 | 긴장감 + 예측성 둘 다 | 코드 복잡도 ↑ |
| 회피 대시 | 가장 "지능적" 보스 | 좌절감 + 결정론 깨짐 |

**좀비팡 결정 우선순위**:
1. 결정론 (테스트 가능성)
2. Ethics 안전성
3. 사용자 학습 가능성 (60초 마이크로세션)
4. 구현 비용 (MVP)
5. 시각적 매력

## 6. Phase별 조절 메커니즘

**개념**: 같은 공식 + Phase별 다른 파라미터 (다이얼 조절).

**예시: 8자 궤도 채택 시**

| Phase | 챕터 | 반경 R | 회전속도 ω | 미니언 수 | 체감 |
|-------|------|--------|------------|----------|------|
| 1 | Ch1 | 80px | 0.5 rad/s | 0 | 큰 8자, 느릿 |
| 2 | Ch2 | 100px | 0.7 rad/s | 2 | 조금 빨라짐, 신입 합세 |
| 3 | Ch3 | 120px | 1.0 rad/s | 4 | 신입+과장 4마리 |
| 4 | Ch4 | 130px | 1.3 rad/s | 6 | 회전 가속 |
| 5 | Ch5 | 150px | 1.6 rad/s | 8 | 가장 큰 ∞, 가장 빠름 |

**핵심 코드**:
```ts
x = cx + R[phase] * Math.sin(2 * ω[phase] * t)
y = cy + R[phase] * Math.sin(ω[phase] * t)
```

→ 한 함수에서 5단계 난이도가 나옴.

```

↑   탭영역  ↓   ← 시계방향 테두리만 따라 이동
↑    (빈    ↓     중앙은 비어 있음
└──←──←──←──┘
```
**장점**: 손가락 가림 없음 / **단점**: 보스 무게감 ↓

### F. 진자 운동 (pendulum)

```
═══●═══   ← 천장 고정점
    ╲
     ╲      x = cx + L·sin(ωt)
      CEO   y = topY + L·cos(ωt)
```
**장점**: 야근/사옥 분위기 친화 / **단점**: 속도 느려 임팩트 약함

### G. 격자 점프 (grid hop)

```
┌──┬──┬──┬──┬──┐
│  │CEO│  │  │  │   ← 3×5 격자, 1.5초마다 인접 칸으로 ⚡

```
**장점**: 결정론 + 예측 / **단점**: 8비트 느낌, 보스 무게감 ↓

### H. 도주 (away from tap)

```
[마지막 탭 = 좌상단]
┌──────────────┐
│ 👆           │
│         CEO →│   ← 최근 탭의 반대 방향으로 천천히 이동

```
**장점**: "잡으려 하면 도망" 유머 / **단점**: 좌절감 위험

## 8. 조합 가능성

### 조합 ① : 단일 패턴 (조합 X)
```
Ch1 ─ 8자 ─ Ch2 ─ 8자 ─ Ch3 ─ 8자 ─ Ch4 ─ 8자 ─ Ch5 ─ 8자
       (반경/속도만 Phase별 증가)
```

### 조합 ② : Phase별 다른 패턴 (변신)
```
Ch1: Patrol → Ch2: Patrol+점프 → Ch3: 8자 → Ch4: 8자+텔레포트 → Ch5: 무작위
```

### 조합 ③ : 베이스 + HP 단계별 격노 (3-phase rage)
```
HP 100~67%: 정상 8자
HP  67~34%: 1.3× 빠른 8자  ← Bible §3 녹→황 색상과 동기화
HP  33~0% : 8자 + 텔레포트 ← Bible §3 황→적 색상과 동기화
```

### 조합 ④ : 베이스 + Phase별 추가 메커닉 **(✅ 채택)**

```
Ch1: 순수 8자 (이동만)
Ch2: 8자 + 미니언 2마리
Ch3: 8자 + 미니언 4마리
Ch4: 8자 + 미니언 6마리 + HP 50%부터 격노 1단계
Ch5: 8자 + 미니언 8마리 + HP 67%/33% 2단 격노
```

## 9. 채택 결정

**🎯 8자 궤도 + 조합 ④**

**채택 근거**:
1. **결정론 100%** — sin(t) 공식, IRandom 의존 없음
2. **Ethics 안전** — Bible §7 안티패턴 0건 충돌
3. **Bible §3 연계 자연스러움** — "HP 3등분 색상 변화"와 격노 단계 매칭
4. **단일 함수 + 다이얼** — MVP 출시 빠름
5. **확장 여지** — 후속 spec에서 텔레포트/패턴 변화 추가 가능

**의도적으로 거부한 옵션**:
- 회피 대시 — Ethics #10 carrot/stick + 결정론 위반
- 랜덤 텔레포트 단독 — Ethics #4 슬롯머신화
- Phase별 패턴 변신 (조합 ②) — MVP 시점 학습 부담 ↑
